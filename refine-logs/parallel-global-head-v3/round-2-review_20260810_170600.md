# PCLD-16 Round-2 方法审稿

## Verdict

**REFINE**

**Weighted overall score: 8.25/10**

**Drift warning: NONE。** 本轮方法保持了 immutable contract：完整 16 位同时输入；每个输出位置无 causal mask 地看到全部 16 位；一次调用同时输出唯一 `[B,16]` 链；Top16 仅为每位置候选轴；没有在线 GRU/selected-token feedback、串行 target decode/seed、iteration/Jacobi、beam/tree/trie/forest/multipath，也没有额外在线 target forward。以下建议全部留在该合同内。

Round-1 的三个核心数学 blocker 已被实质修复：方法不再依赖 Domino `W_s s` 统计量；`U=0` 给出了正确的 base identity；原来无下界的 worst-prefix surrogate 被改成了有界、可稳定实现的风险项。但当前仍不能 READY：teacher ceiling 已经很强，真正未解的问题已明确收缩为“在线 full-block lattice 是否能在 prompt-disjoint 数据上预测足够有用的 residual”；同时，clean-support 定义、数值等价边界、loss 实现和 EAL–cycle-time 联合系统门仍需写死。READY 仍要求 overall ≥9 且无 blocker，本版不满足。

## 已证事实、推断与待证假设

### 已证事实

1. `scripts/train_domino_backbone_lora.py` 的 full-B16 materializer 构造 `context + anchor + gold0..14`，并读取 `last_hidden_state[:, context_length:context_length+16]`。因此 target row 0 是 `anchor → y0`，row 15 是 `y14 → y15`，16 行完整，没有遗漏 position 0 或 position 15。
2. DFlash 返回自身 final-norm parallel hidden `H`；base logits 是 `target.lm_head(H)`。实际 Qwen3-4B 的 hidden size 是 2560，且当前 checkpoint `tie_word_embeddings=true`。
3. R047 validation-select 的 exact teacher ceiling 已成立：1175 blocks/147 prompts 上，base EAL `6.0685131`，Domino `7.2395530`，target-candidate teacher `10.5971817`，gold oracle `10.9092566`；teacher 回收 base→oracle gap 的 93.55%，gain/loss/tie 为 906/3/266，harm 0.2553%。三个 loss 都包含 target-top1 与 gold 不一致。chat/code/math teacher EAL 分别为 6.756/10.191/14.683，均高于各域 Domino。
4. 因而 `Δ_i*=T_i-H_i` 在 candidate scoring 上存在很高的离线效用。它比 Domino correction statistic 更完整，也天然覆盖 position 0。
5. 既有负结果不能粉饰：PLC 约 6.0934；PGCF disjoint global-local 仅 +0.01385 且置信区间跨零；JAPD capacity 很高但 disjoint full-fit 仅 EAL 6.3862、recovery 5.51%、harm 18.16%；LoRA/full-backbone/target-KL 的 R043–R046 增益均极小或不显著。JAPD D256 的 full-fit 曝光不足是 confound，但不能据此把负结果改写成成功。
6. 当前明确组件的可训练参数数是 **3,826,688**，前提是：H/E 两个线性投影、5 个 scalar、position/rank embedding、input LN、2×标准 D256-FFN1024 encoder、16-query MHA+LN+query embedding、`U:256→2560` 含 bias；不含 query FFN 或独立 anchor projection。
7. clean teacher correction 范围约 `[-48.75, 43.75]`，base-Top16 score std 中位数 2.60；normalized teacher margin 中位数 5.30、p1 0.0777。这使显式 `exp` 和无温度 KL 都具有实质数值/优化风险。

### 合理推断

1. target-hidden residual 比 Domino-code residual 更自洽：它直接对应同一个 frozen `lm_head` 下的 predictive-state difference，不再声称一个未经验证的 256-d Domino GRU statistic 是 sufficient statistic。
2. `U=0` 在实数代数下使 correction 为零，所以 head 精确回退 DFlash base score；这解决了 Round-1 中“zero-init 回退错误基线”的 blocker。
3. full-node global encoder 加 16 个并行 query 的信息条件严格强于 local-only head，且仍符合一次全并行函数合同。但“信息条件更强”不等于“能够跨 prompt 学到可泛化映射”。
4. teacher ceiling 10.597 说明候选 support 不是当前主瓶颈；瓶颈转移到 student predictability、优化与系统开销。

### 待证假设

1. 在线可见的 DFlash lattice 能预测 `Δ*` 中足够影响 candidate ranking 的部分，并在 prompt-disjoint split 上超过 Domino，而非只在 same-set 拟合。
2. global all-256-node 条件相对 local-only 有稳定、跨 seed、跨域增益。
3. latent supervision 相对 candidate-only student 有独立价值，而不是 KL/CE 的重参数化。
4. 3.83M head 的实际 kernel、gather、attention 和 dtype 开销允许在 EAL 提升后仍达到 SGLang TPS ≥1.15× Domino。

## 技术审查与剩余 blocker

### Blocker 1：LM-head 权威来源与“精确 identity”的数值边界尚未写死

方法应以 `target.lm_head.weight[C]` 作为 lexical row 的唯一权威来源。当前 checkpoint 虽与 `embed_tokens` tied，但方法定义不应依赖一个泛称 `E[C]` 的别名，也不应默认未来 checkpoint 始终 tied。

teacher candidate score 的权威定义应是：

`S* = gather(target.lm_head(T), C)`。

在线 residual 公式可以写成：

`S = B + <target.lm_head.weight[C], Δhat>`，其中 `B = gather(target.lm_head(H), C)`。

但 `target.lm_head(T)-target.lm_head(H)` 与 gathered weight 对 `T-H` 的 FP32 dot 只在实数代数中严格相等。BF16 GEMM、FP32 gathered dot、bias、tie 和 kernel accumulation order 都可能造成微小差异。因此必须区分：

- **代数 identity**：`U=0 ⇒ S=B`；
- **实现 identity**：在指定 dtype/kernel 下逐元素容差与 non-tie argmax parity；
- **teacher equivalence**：residual reconstruction 与直接 `lm_head(T)` gather 的 FP32 容差，而不是宣称 bitwise 相等。

### Blocker 2：clean-support 必须是一个连续前缀 mask，并对所有损失统一

当前“clean support”概念是对的，但必须成为唯一、可执行的公式，而不是各 loss 各自解释。建议固定：

`M_{b,i}=∏_{j=0}^{i} 1[y_{b,j}∈C_{b,j}] · 1[argmax_k S*_{b,j,k}=y_{b,j}] · 1[stable_{b,j}]`。

这里 `stable` 用预注册的 non-tie tolerance 定义。这个 mask 表示截至位置 i 的 canonical gold 前缀仍在 candidate support 内，且 teacher candidate top1 与 gold 一致；一旦前面失效，后续位置不得继续作为“clean teacher-forced chain”训练样本。latent、safe-risk、KL 都必须用同一个 `M`。

聚合也必须先 block-normalize，再 prompt-balanced：每个 block 先除以有效位置数，每个 prompt 再等权，不能让长 prompt、更多 block 或 code/math 域暗中主导 loss。validation 也报告 clean-support coverage、按位置 coverage 和按域 coverage。否则 12,541 行级统计会把相关位置误当独立样本。

### Blocker 3：safe-risk 需要写成稳定 FP32 `logsumexp`

有界 worst-prefix 思路已经比 Round-0 正确，但实现公式必须固定为：

`L_safe = τ · logsumexp([0, log(w_i)+(γ-m_i)/τ]_{i:M_i=1})`，

其中 `w_i=(16-i)/16`、`γ=τ=0.1`，在 FP32 中计算；不得先显式计算 `exp((γ-m)/τ)`。空 support block 的行为也要明确为零损失并单独计数。

它仍不是一个形式化“certificate”，只能称为 bounded, early-weighted risk surrogate。最终 rare-early-harm 的证据必须来自 disjoint canonical acceptance 的位置条件 harm、prompt bootstrap CI 与最坏域报告，不能由训练 loss 名称替代。

### Blocker 4：candidate KL 的 T=1 几乎退化成硬标签

在 observed margin 尺度下，T=1 teacher distribution 接近 one-hot，因此它很难作为“软结构蒸馏”对照。固定 `T=2`，并使用标准 `T²·KL(p_T^* || p_T)`；同样应用连续 clean-support mask 和 prompt-balanced aggregation。不要扫温度，不要增加调参树。P2 的 no-latent 对照必须保留相同架构、相同 safe loss 和相同 T=2 KL，只删 latent regression，才能判断 predictive latent 是否贡献了超出 candidate supervision 的信号。

### Blocker 5：删除绝对 latent RMSE hard gate；PCA 不得作为结构上界或 STOP 条件

`Δ*` 各维按训练 std 标准化后，绝对 RMSE≤0.25 与 candidate ranking/EAL 没有经过校准，可能错误杀死一个 score-useful student，也可能放过 score-useless reconstruction。P1 的 binding gate 应只看 candidate score/margin、canonical recovery/harm/J2 和 EAL，不把 absolute latent RMSE 作为 hard stop。latent cosine/RMSE 可作为诊断。

普通 rank-256 PCA 只最小化 hidden L2，不是 candidate-score 最优子空间的 oracle upper bound。对每行动态 candidate matrix `A_i∈R^{16×2560}`，只要 `A_iU` 多数样本满 row rank，`r≥16` 时 oracle `g_i` 原则上可表达任意 16 维 candidate correction；真正瓶颈是从 online lattice 预测 `g_i`。因此撤回 PCA hard-stop 是正确的。最多报告 train-only PCA latent reconstruction diagnostic，且它不是 gate、不是 ceiling、失败时不能关闭架构。更简单的选择是本轮完全删除 PCA。

### Blocker 6：P0 的 zero-init identity、global visibility 与训练动力学要拆开验

当 `U=0` 时，最终 score 对任意 remote node 都不变；因此不能在 zero-init 最终输出上要求“remote intervention 改变 score”，这与 identity 本身矛盾。P0 应拆成：

1. **identity receipt**：`U=0` 时 score 与 base 在容差内一致，non-tie argmax 完全一致；
2. **visibility receipt**：在固定非零 probe `U` 或一个短训 checkpoint 上，只改 remote node 会改变相应 query 的 `g_i`/score；zero-init 时可检查 `∂g_i/∂x_remote ≠ 0`，而不是最终 score；
3. **gradient receipt**：首步 `grad(U)>0`；因 U=0，上游 encoder 首步 gradient 为零是允许且预期的；一次 optimizer update 后，再证上游 gradient 非零；
4. **simultaneity receipt**：输出形状严格 `[B,16]`，一次 tensor argmax，无位置循环中的 selected-token feedback。

同时冻结 exact architecture：两层标准 D256/8-head/FFN1024 full-attention encoder；16 个 learned queries 的一次 MHA+LN；无 query FFN、无独立 anchor projection；总参数 3,826,688，≤5M。这样可避免“约 3.9M”留下实现漂移空间。

### Blocker 7：EAL 门必须与 `EAL+1` 和 cycle time 联合

speculative cycle 实际输出 token 数是 `EAL+1`。若 PCLD 只达到合同中的 `1.15× Domino EAL = 8.3255`，而 Domino EAL 为 7.2396，则同 cycle 成本下的输出比仅为：

`(8.3255+1)/(7.2396+1)=1.1318`，

不足 1.15× TPS。最终必要条件应从 P0 起就写入：

`T_P/T_D ≤ (EAL_P+1)/(1.15·(EAL_D+1))`。

同 cycle 成本时，最低 EAL 约为 8.4755。为了给 head 开销留余量，方法设计目标应设为 **EAL≥9.0**；此时容许 PCLD cycle time 约为 Domino 的 1.055×。合同原有的 EAL≥8.3255 仍是必要的最低统计门，不能删除，但不得再把它描述成足以推出 1.15× TPS。P0 latency、P3 scale 决策和 P4 SGLang 都要报告该联合不等式，不能到 P4 才发现不可达。

## Novelty 边界

### 相对既有内部路线

- **相对 PLC**：不是继续预测 Domino `W_s s`，而是直接蒸馏 frozen target 的 clean predictive hidden residual；覆盖 16 个位置，包括 position 0；在线没有 Domino GRU rollout。这是实质机制变化。
- **相对 PGCF**：不是只做 candidate feature fusion，而是有明确的 offline target-state teacher 与 residual scoring identity；但 PGCF 的 disjoint failure 仍警告 global access 可能只增加 same-set capacity。
- **相对 JAPD**：不是将 candidate logits 压进一个固定低秩 score head，而是预测共享 hidden residual，再通过每样本动态的 `lm_head.weight[C]` 投影到候选轴；但若 latent/no-latent 对照无差异，审稿人仍会合理地把它视为 candidate-KL reparameterization。
- **相对 R043–R046 和 backbone adaptation**：PCLD 改变的是 head 的 information condition 和 teacher target，而不是继续扩大 DFlash/LoRA 参数；不过这些负结果证明“更多 target supervision/更多参数”本身没有转化保证。

### 相对外部工作

- **Your LLM Knows the Future** 已经使用 predictive latent alignment，因此不能宣称“首次蒸馏未来 target hidden”或把 predictive latent 本身作为核心 novelty。
- **DFlare** 已通过 layer-wise fusion 注入更广的 target-layer knowledge，并扩大训练数据至 2.4M，报告相对 DFlash 约 5–11% wall-clock 提升。因此不能宣称“首次为 parallel drafter 注入丰富 target knowledge”；PCLD 的边界是 strict one-call/full-block/candidate-only one-chain correction。
- **DSpark** 明确把 parallel drafter 的 acceptance decay 归因于缺少 intra-block dependency，但它使用 lightweight sequential module，违反本项目合同。不能说 PCLD 首次发现该问题。
- **PTP** 说明单次并行函数原则上可以表达 joint dependency，因此不能泛称“首次解决 parallel dependency”。

若结果成立，最稳妥的贡献表述是：**在禁止 sequential feedback、额外 target inference 与 multipath search 的严格场景下，通过 full-block global residual distillation 恢复可泛化的 block 内依赖，并取得端到端吞吐收益。**

## P0–P4 实验计划审查

### P0：保留，但改成 mechanics + teacher + system 三类 receipt

保留已完成的 exact teacher ceiling 10.597，不要重复把 teacher ceiling 当 student evidence。补充 Blocker 1/2/6 的 row、lm-head、dtype、identity、visibility、gradient、mask receipts；同时测 micro latency 和 `(EAL+1)/cycle` 所需边界。PCA 不进入 P0 hard gate。

### P1：512-block capacity gate 保留，但只证明优化/容量

P1 只回答“该固定架构能否在小数据上把 score 和 acceptance objective 优化起来”，不能支持泛化。hard gate 应基于 candidate score recovery、gold margin、canonical EAL、harm、J2；删除绝对 latent RMSE≤0.25。若 same-set 都不能明显接近 teacher，则 STOP 合理。

### P2：这是决定机制是否成立的核心门

必须是 prompt-disjoint、3 seeds、相同训练预算与 data order 的：

- PCLD-global；
- local-only；
- no-latent（T=2 candidate KL + safe risk，删 latent regression）。

主证据是 global 对 local 的 paired prompt bootstrap CI，以及 global 对 Domino 的 recovery/harm/J2、按位置和按域结果。no-latent 只用于回答 latent 的增量机制，不应膨胀为更多 loss grid。若 global-vs-local 不稳定或 global 无法超过 Domino，停止 25K/100K 扩展；不得用 JAPD 曝光不足作 post-hoc rescue。

### P3：25K 有合理先验；100K 必须严格条件触发

25K 的合理性来自：当前 student predictability 未证，而 R043–R046/PGCF/JAPD 已显示 transfer 很难，直接 100K 不经济。只有 P2 跨 seed 通过，且 25K prompt-disjoint fixed EAL、harm 和联合系统门呈一致正趋势，才进入 100K。100K 不是“为了看看更多数据会不会救活”，而是验证已出现的 transfer scaling。不要因为 DFlare 使用 2.4M 数据就自动扩大本项目预算。

### P4：fixed、dynamic、SGLang 顺序正确，但门应提前耦合

fixed canonical 是方法有效性的主统计门；dynamic 检查实际候选/调度；SGLang 给最终 TPS。三者都必须同 job、同 prompt、同 batch/服务配置比较 Domino。最终必须同时满足 EAL 合同门和测得的 cycle-time inequality。若 EAL≥9.0 仍因 kernel/gather 不能达到 TPS，结论应是系统失败，不能只报告 acceptance。

## Simplicity：应删除或合并的复杂度

1. **删除 PCA hard-stop**；最好本轮连 PCA 模块都不实现，只允许离线、train-only、非门控 diagnostic。
2. **删除未使用的独立 anchor input/projection**。full 16 DFlash rows 已包含 anchor predictive row，新增 anchor 支路只会扩大漂移面。
3. **不增加 query FFN、第三层 encoder、第二个 output head 或更多 loss family**。先冻结 3,826,688 参数版本。
4. 将 latent、safe、KL 的 support/normalization 合并为一个公共 `M` 和一个 prompt-balanced reducer，避免三个损失各自定义样本集。
5. 消融只保留 global/local/no-latent 三个必要对照；不做温度、rank、层数、tau 的大网格。
6. D0 exposure audit 只作为解释既有 JAPD 负结果的科学审计，不作为 PCLD 失败后的救援通道，也不触发重新训练 JAPD。

## 最强拒稿理由

当前最强拒稿理由不是 teacher 不够好，而是：**PCLD-16R 只证明了 clean target hidden 在离线 candidate set 上具有 10.597 的高 oracle-like ceiling，却没有证明在线 DFlash full-block lattice 能跨 prompt 预测这个 residual。** 既有 PLC、PGCF、JAPD、LoRA/full-backbone 与 target-KL 结果共同表明，same-set capacity、更广信息条件、更多参数或更强 target supervision 都可能完全不转化。若 global-vs-local 与 latent-vs-no-latent 不成立，本方法在功能上仍只是一个低秩 candidate score/KL 重参数化。并且，即使只达到 EAL 8.3255，同 cycle 成本下也只有 1.1318× 输出率，尚不足最终 1.15× TPS。

## 逐项可执行最小修订

1. 把所有 `E[C]` 改为 `target.lm_head.weight[C]`；把 `gather(target.lm_head(T),C)` 定为 teacher score 权威；写清 BF16/FP32、bias、容差和 non-tie parity。
2. 写出唯一连续 clean-support mask `M_{b,i}`；latent/safe/KL 共用；先 block-normalize，再 prompt-balanced；报告 coverage。
3. 把 safe loss 固定成 FP32 `τ·logsumexp([0, log w_i +(γ-m_i)/τ])`，禁止显式 exp；改称 bounded early-weighted surrogate，不称 certificate。
4. 将 candidate KL 固定为 `T=2` 且乘 `T²`；不做温度 sweep。
5. 删除 P1 的 absolute latent RMSE hard gate；PCA 最多是非门控 train-only diagnostic，绝不能失败即 STOP。
6. 将 P0 拆成 identity、visibility、gradient、simultaneity receipts；承认 U=0 时上游首步 gradient 为零，并验证一次更新后恢复。
7. 锁定 FFN1024、无 query FFN、无独立 anchor projection和 **3,826,688** 参数，杜绝“约 3.9M”实现漂移。
8. 从 P0 起加入 `T_P/T_D ≤ (EAL_P+1)/(1.15(EAL_D+1))`；保留 EAL 8.3255 必要门，同时设设计目标 EAL≥9.0。

## 严格不漂移的下一版方法

下一版只应是 **PCLD-16R.1**，不换架构族：DFlash 一次产生完整 `H[16]` 和每位置 base Top16；离线 target 仅用于构造严格对齐的 `T[16]` 与 `Δ*=T-H`；线上把 256 个 candidate nodes 经两层无 causal mask 的 D256/8-head/FFN1024 encoder，再由 16 个 learned queries 同时读取全体 nodes，输出 `g[16,256]`；共享 `U` 得到 `Δhat[16,2560]`；用 `target.lm_head.weight[C]` 一次并行算 corrected candidate scores；单次 argmax 得到唯一 `[B,16]`。U 零初始化，参数固定 3,826,688。训练只保留统一 clean-support 下的 standardized SmoothL1 latent loss、稳定 bounded safe-risk 和 T=2/T² candidate KL；评估只保留 P0 receipts、P1 capacity、P2 global/local/no-latent、条件式 25K/100K、fixed→dynamic→SGLang，以及 EAL+1/cycle-time 联合门。

这版已经值得进入一次严格 P0/P1/P2，而不值得直接进入 100K。若 P2 的 prompt-disjoint global advantage 和 latent increment 都不成立，应停止该方法线，不再用曝光、PCA、更多 backbone 参数或更大数据作事后救援。
