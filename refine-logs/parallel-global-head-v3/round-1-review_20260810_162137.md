# PCLD-16 Round-0 方法审查

**CALIBRATION：none**。评分以仓库内 PLC、PGCF、JAPD、R043–R046 的真实正负结果为锚，不使用外部已知优/劣 proposal 样本。  
**Weighted overall：6.15 / 10**。权重：Problem Framing 15%、Technical Soundness 20%、Novelty 20%、Method Design 20%、Experimental Plan 15%、Simplicity 5%、Venue Readiness 5%。  
**Verdict：REFINE**。存在三个 blocker：zero identity 数学错误、latent target/loss 不足以支持“sufficient statistic”主张、worst-prefix loss 无下界且不是实际 certificate。  
**Drift Warning：NONE**。当前方案及下面推荐的 target-hidden-residual 修订均可严格留在 immutable contract 内。

## Immutable contract 核对

当前 PCLD 在线图按文字定义满足：

- 一次输入完整 `[B,16,*]`；
- 256 个 candidate nodes 做无 causal mask 的全局混合，每个 code query 读全部节点；
- 一次输出 `[B,16,16]`，一次逐位置 argmax 得唯一 `[B,16]`；
- Top16 只是位置内候选轴；
- 无 selected-token feedback、GRU rollout、串行 target decode/seed、iteration/Jacobi、beam/tree/trie/forest/multipath；
- clean Domino/target trajectory 只作离线 label；
- 无普通 verifier 之外的在线 target forward。

参数和延迟只有“合理路径”，尚非已证：JAPD D256 的 `4.54M`、complete eager `0.9993x Domino` 不能直接替代 PCLD 的完整 profile。

## 关键技术审计

### 1. `delta_i*=W_s s_i*` 与 full16 索引

**已证事实：**

- released checkpoint 的 `embed_proj` 第一层确实可拆为  
  `W_h H_i + W_s s_i`；实际配置 `gru_hidden_dim=1024`、`emb_dim=256`，且未启用 `use_bias_norm/use_bias_gate`。
- `prefix_gru([anchor,y0,...,y14])` 的 batched outputs 行 `0..15` 分别是：
  - row 0：消费 anchor 后、预测 `y0` 的 state；
  - …
  - row 15：消费 `y14` 后、预测 `y15` 的 state。
- 因此，只要 materializer 取 `states[:,i]`，position 15 是完整的，不是 off-by-one。必须用“batched teacher vs 16 次手工 recurrence”逐行 parity 测试锁死。

**必须降级的表述：**

`W_s s_i` 只是在固定 `H_i`、固定 released `W_h/W_out` 下重建 Domino correction logits 的**代数充分量**；它不是 clean trajectory、target token 或 accepted-prefix utility 的统计 sufficient statistic。当前标题和 thesis 把两者混为一谈。

**严重问题：**

`SmoothL1(RMS(hat_delta), RMS(delta*))` 丢弃 code norm，而在线量是：

\[
\mathrm{SiLU}(W_hH_i+\lambda_i\hat\delta_i).
\]

方向相同但幅度不同会跨越 SiLU 的线性/饱和区域并改变 candidate margins。`cosine>=0.98` 也不能证明 logits 可重建。应改成保幅的、按训练集固定逐维尺度 whitening 后的 Huber/MSE，并同时 gate candidate-logit RMSE/KL 和 margin parity。

另一个 position-0 风险不能忽略：released Domino 因 `pure_draft_prefix_len=1` 在线不对 position 0 应用 correction。因此 `delta_0*` 虽可计算，却是未部署的 counterfactual teacher，不能默认是可靠监督。

### 2. 当前 zero identity 是错误的

初始 `W_delta=0` 只能得到 `hat_delta=0`；gate 最后一层零初始化还会给 `sigmoid(0)=0.5`。但无论 gate 是 0 还是 0.5：

\[
S_{ik}^{(0)}
=B_{ik}+\langle W_{\text{out}}[C_{ik}],
\mathrm{SiLU}(W_hH_i)\rangle,
\]

通常都不等于 `B_ik`。所以“step0 精确回退 pure DFlash”不成立。这是实现前 blocker，不是措辞问题。

若坚持 Domino-code 版，至少需要外层零门，或使用

\[
B+\langle W_{\text{out}},
\mathrm{SiLU}(W_hH+\hat\delta)-\mathrm{SiLU}(W_hH)\rangle,
\]

但后一式改变了 teacher score 语义。继续修补会让 gate、latent 和 basis 更纠缠。

### 3. 与 PLC、PGCF、JAPD、adaptation 的新颖性边界

**已证事实：**

- PLC 已经提出并实现“并行预测 `W_s s_i`、复用 Domino `W_h/W_out`、删除在线 GRU”。
- PCLD 的真实新增是 clean teacher forcing、full16、候选不先压 modes、full-node global query、candidate-only projection 和 worst-prefix loss。
- PGCF/JAPD 已证明 full16 frozen-feature selector 有容量、低延迟，但 held-out/global-local transfer 几乎没有。
- R043–R046 表明 LoRA、Domino-head adaptation、588M full adaptation、full16 full-vocab exact-prefix KL 都没有产生可信 transfer。

**推断：**

当前 PCLD 不是“重复 JAPD loss sweep”，但仍明显是 PLC 路线的第二版。clean state 可能比 on-policy code 更适合 acceptance-relevant branch，这是合理假设；它不是尚已证明的新信息源。

**待证假设：**

- clean Domino code 可由在线 DFlash full16 lattice 跨 prompt 预测；
- clean code 比 target candidate KL 提供独立增益；
- candidate-specific global mixing，而不是新的 teacher/loss，本身有必要。

三者缺一，投稿叙事都会退化为 PLC refinement 或 another distillation head。

### 4. Worst-prefix “certificate”

当前式

\[
\tau\log\sum_i \exp((\gamma-m_i)/\tau)
\]

有两个 blocker：

1. 当所有 margin 被无限放大时，loss 趋于 `-∞`，没有下界；
2. 它优化的是 block 内最小逐位置 margin，不是 harm 的统计 certificate；最小项还可能长期是 position 15，并不天然专注 rare early harm。

应更名为 `smooth worst-prefix risk`，改成有下界的：

\[
L_{\rm safe}^{(b)}
=\tau\log\left(
1+\sum_{i<h_b}w_{bi}
\exp((\gamma-m_{bi})/\tau)
\right),
\]

其中 `w_bi` 是预先固定、随剩余 prefix utility 递减的权重。它仍只能是 surrogate；真正 certificate 仍是 untouched prompt 上的 harm 上界、gain/loss 计数和 bootstrap CI。

### 5. D0 exposure audit

D0 有科学动机：4,096-block full-fit 只有 1,518 updates、约 6 epochs，且 step 1500 仍在上升，因此不能把结果写成 frozen features 的信息论上限。

但它**不是 PCLD 的必要前置实验**，且现有 result-to-claim 已明确关闭 exact JAPD 延长训练。20K updates 相当于约 79 epochs，极易被读成事后 rescue。

建议：

- 从 P0–P4 主链删除；
- 如必须做，另名为 `JAPD exposure-only retrospective audit`；
- 在启动前冻结 20K 单点、完整 schedule、全部指标和“不进入 PCLD checkpoint/baseline selection”的隔离条款；
- 无论结果如何都不重开 JAPD M2，也不以其结果改变 PCLD GO/NO-GO。

### 6. P0–P4 与 25K/100K

当前 gates 总体可证伪，但需修订：

- **P0 前新增 teacher-ceiling gate**：clean Domino candidate policy 的 EAL、harm、position-0/15 parity。如果 clean teacher 本身不能明显越过 Domino，就不应蒸馏。
- **P1**：`cosine>=0.98` 改为保幅 latent error、candidate-logit RMSE/KL、margin agreement；same-set 只能是 mechanics/capacity，不作机制证据。
- **P2**：至少三 seed；`global/local/no-latent` 必须完全 matched。199-prompt diagnostic 只开一次，所有 architecture、schedule、bias 在 select 上冻结。
- **P3**：25K prompts 是合理的条件性 pilot，不是浪费；100K 只有在 P2 过、25K 达到预注册 EAL/global-local/latent-necessity 门且 held-out 曲线仍有正斜率时才合理。单纯 train loss 下降不能授权 100K。
- **P4**：final fixed 必须使用新 sealed prompts 上的同作业 ratio，而不是机械套 development 的 `8.3254859`；dynamic 与 SGLang 继续在 checkpoint、gate、kernel 全冻结后顺序打开。最终 efficacy 需要 seed spread 和 prompt-level CI。

## Target-hidden-residual 修订评估

建议优先考虑，但不能默认接受。

定义 target clean predictive hidden：

\[
T_{0:15}
=\mathrm{TargetHidden}([anchor,y_0,\ldots,y_{14}]),
\]

其中 row `i` 预测 `y_i`。若 DFlash final hidden `H_i` 和 `T_i` 都由同一个冻结 LM head `E` 投影，则：

\[
B_{ik}=\langle E[C_{ik}],H_i\rangle,
\]

\[
B_{ik}+\langle E[C_{ik}],T_i-H_i\rangle
=\langle E[C_{ik}],T_i\rangle.
\]

这是对 candidate target logits 的**精确代数恒等式**。它比 Domino-code 版更自洽：

| 项目 | Domino-code 版 | Target-hidden residual 版 |
|---|---|---|
| teacher | 256-d `W_s s*` | 2560-d `T-H`，再低秩预测 |
| position 0 | 未部署的 Domino counterfactual | 天然覆盖 |
| zero identity | 当前公式不成立 | `W_up=0` 时严格成立 |
| frozen lexical basis | 额外依赖 Domino `W_h/W_out` | 直接复用已有 LM-head rows |
| 与 PLC 距离 | 很近 | 明显更远 |
| 最接近先例 | PLC | *Your LLM Knows the Future* 式 predictive-latent alignment |
| 主要负证据 | PLC 失败 | R043–R046 target distillation/adaptation 失败 |

但“共享 LM head”只证明 score 恒等式，不证明 `T-H` 是易预测、低秩或跨 prompt 泛化的 representation。若训练最终只优化 `E[C]hat_delta` 上的 KL，它就是 candidate KL 的低秩重参数化，并未越过 R046。必须用 matched `without latent loss` control 证明 hidden residual supervision带来额外 transfer，才能保留 latent mechanism claim。

相对 *Your LLM Knows the Future*，不能声称 predictive-latent alignment 本身新颖。可成立的贡献只能是：把 16 个 clean AR predictive residual 在一个 candidate-conditioned full-block noncausal student 中同时蒸馏，在线只做一次单链 candidate decision，并证明 global context 与 latent target 都是必要因果因素。

## 最强拒稿理由

> PCLD 当前并未展示一个新的、可识别的信息机制。核心 teacher statistic 和 frozen correction basis 已由失败的 PLC 提出；clean prefix、full16 和新 loss 只是该路线的修订。更严重的是，当前公式不具所宣称的 pure-DFlash zero identity，latent loss删除了在线非线性所需的幅度，worst-prefix objective 还无下界。结合 PGCF/JAPD 与 R043–R046 的负结果，没有证据表明 frozen DFlash observables 能跨 prompt 预测 clean sequential code，也没有证据表明 latent supervision优于 target KL。因此目前最合理解释仍是“对既有失败 selector/distillation 路线重新参数化”，而不是已具投稿价值的新机制。

## 逐项可执行修订

1. **CRITICAL：切换为 target-hidden residual 主版本。** 删除 Domino `W_h/W_out/W_s` teacher/basis 和 position-0 counterfactual。
2. **CRITICAL：锁死 row geometry。** `T[:,0..15]` 对应 `[anchor,y0..y14]`，手工递推与 batched target parity；单独断言 position 15。
3. **CRITICAL：建立 exact identity。** `hat_delta=U g`，`U` zero-init；逐 token 验证 step0 与 pure DFlash 完全一致。
4. **CRITICAL：修复 safe loss。** 使用带 `1+sum exp` 的有下界 smooth risk；不得称形式化 certificate。
5. **CRITICAL：保留 latent 幅度。** 使用固定训练集尺度 whitening 的 Huber/MSE，不做逐样本 RMS direction-only regression。
6. **IMPORTANT：加入 matched KL-only control。** 相同 global head、数据、更新数，仅去掉 latent loss；不显著更差则 latent claim 失败。
7. **IMPORTANT：保留 parameter-matched local mask control。** global-local 不达门则 full-block mechanism claim 失败。
8. **IMPORTANT：P0 加 teacher score parity/ceiling。** `B+E(T-H)` 必须逐 candidate 等于 target clean logits，并报告对应 EAL/harm。
9. **IMPORTANT：D0 与方法主链隔离或删除。**
10. **IMPORTANT：P2 三 seed；P3 25K 条件试点；100K 只能由真实 held-out scaling signal授权。**

## 应删除或合并的复杂度

- 删除 Domino correction input row、Domino output basis 和 continuous `lambda` gate；
- 删除 D0 作为主方法 gate；
- 不同时保留 Domino-clean KL、target KL、latent code 三种 teacher；
- 不使用逐样本 RMS-normalized code loss；
- 不增加 D512、额外 head、第二 expert、post-hoc per-domain gate；
- candidate-specific full-node mixer与一次 position query保留，它们是唯一需要验证的全局机制。

## 严格不漂移的下一版方法

**建议名称：PCLD-16R，Parallel Clean Predictive-Residual Distillation。**

在线一次 DFlash forward 后取得 `H[16]`、pure-base `Top16` IDs/logits 和冻结 LM-head rows。256 个 candidate nodes 由 `H_i`、`E[C_ik]`、base score/rank、position 构成，经两层 full noncausal mixer；16 个 position queries 各自 cross-attend 全部 256 nodes，得到 `g_i∈R^256`。唯一新 residual 为：

\[
\hat\Delta_i=Ug_i\in\mathbb R^{2560},
\qquad U\text{ zero-init},
\]

\[
S_{ik}=B_{ik}+\langle E[C_{ik}],\hat\Delta_i\rangle.
\]

一次 `argmax_k` 同时产生唯一 `[B,16]`。无 gate、无 Domino basis、无在线 target、无串行或迭代。

离线 target 为 `Delta_i*=T_i-H_i`，严格覆盖 row0–15。训练只保留：

\[
L=L_{\rm safe}+\alpha(t)L_{\rm latent}+\beta L_{\rm targetKL},
\]

其中 `L_latent` 保幅、`L_safe` 有下界。核心 controls 只有 local-mask 和 no-latent/KL-only。

按 P0 mechanics/teacher ceiling → P1 same-set capacity → P2 三 seed cross-fitted mechanism → P3 条件性 25K/100K scale → P4 sealed fixed/dynamic/SGLang 执行。任何阶段失败都关闭该路线，不转向 causal、iteration 或 multipath。
