## 1. Claims and decisive evidence

### C1 — A lightweight full16 global head is mechanically feasible

**Claim.** A 2,438,400-parameter head can consume the full `16×16` candidate lattice once, provide noncausal all-node visibility, and output one 16-token chain with acceptable A40 latency.

**Decisive evidence.** Gate0 tests; 512-block capacity; complete eager PGCF pipeline `<=1.20×` eager released Domino; no forbidden tensor/dataflow.

**Falsifier.** Capacity thresholds fail after implementation/optimization sanity, or fair complete head latency exceeds the guide without an efficacy-preserving same-mechanism reduction.

### C2 — Held-out gain comes from cross-position candidate information

**Claim.** Full global mixing improves disjoint EAL beyond a parameter-matched local head and uses coherent remote lattice information.

**Decisive evidence.** On R047 15,886/1,175 disjoint split: global-local `ΔEAL>=0.15`, paired prompt-bootstrap 95% CI lower bound `>0`, remote intervention erasure `>=50%`, each domain global≥base.

**Falsifier.** Global≈local, CI crosses zero, or remote intervention preserves most of the gain.

### C3 — Full16 teacher warm-start plus prefix optimization materially beats Domino

**Claim.** With full16 OPB training, PGCF reaches fixed and dynamic EAL at least `1.15×` same-job released Domino.

**Decisive evidence.** Stage-A development≥7.55; frozen development≥8.325485909; preselected single checkpoint passes one-shot fresh formal fixed and dynamic `>=1.15×` Domino and formal per-domain no regression.

**Falsifier.** Genuine disjoint/fresh held-out gate fails. Same-set capacity, oracle, train EAL or token CE cannot substitute.

### C4 — Accepted-length gain survives deployment cost

**Claim.** Same-stack A40 SGLang end-to-end TPS is at least `1.15×` released Domino while retaining higher accepted length.

**Decisive evidence.** Paired same-workload, same-backend SGLang measurement with the frozen primary checkpoint.

**Falsifier.** Fixed/dynamic efficacy passes but final TPS ratio is below1.15.

## 2. Frozen method and controls

### Primary

- `d=256`, heads8, layers2, FFN2x, dropout0;
- 256 full candidate nodes, no attention mask;
- exact2,438,400 trainable params;
- base-Top16 only; no Domino-action candidate union;
- safe log-space prefix loss + `0.05 KL(pT||q)` + finite teacher schedule;
- one invocation and one per-position argmax.

### Controls

1. Domino-DFlash base Top1 identity;
2. released Domino full-vocab correction head;
3. parameter-matched local attention control, identical weights/config except cross-position visibility disabled;
4. remote coherent-triplet intervention, diagnostic-only.

No causal control is needed to authorize the method and no causal implementation is added to the claim-bearing code. Historical causal results remain context only.

## 4. Execution ladder

### G0 — Local implementation and CPU compliance

**Runs:** PGCF-001.

Implement isolated new files; do not modify old tree/causal route semantics. Tests:

- exact shapes `[B,16,16]` and `[B,16]`;
- one-call identity at zero scorer;
- deterministic probe remote sensitivity both directions;
- matched local has no remote response;
- no gold/policy/target in forward signature;
- safe out-of-K, empty KL, finite BF16/FP32 gradients;
- teacher schedule endpoints/continuity;
- exact params2,438,400;
- pure base16 oracle10.909256560;
- source scan/test rejects GRU, causal mask, token decode loop and multiple proposals in claim-bearing module/launcher.

**GO:** all focused tests plus relevant existing tests pass. No GPU authorized before read-only code review of these invariants.

### G1 — A40 mechanics smoke

**Runs:** PGCF-002.

- 32 R047 blocks, one short optimization;
- verify GPU forward/backward, nonzero global gradients, identity before update, full16 labels, no OOM/NaN;
- report peak memory and both head/backbone feature dtypes.

**GO:** all semantic checks pass; no scientific claim.

### G2 — 512-block capacity

**Runs:** PGCF-003 global, PGCF-004 local diagnostic.

Default global must meet:

- gold-in-K accuracy≥0.99;
- hard/nonTop1 accuracy≥0.97;
- base16 oracle-gap recovery≥0.95;
- harmed blocks≤0.01;
- supported Domino-action capacity accuracy≥0.99.

**NO-GO:** failure after optimization/index debugging blocks D1/D3. It does not authorize causal/tree alternatives.

### G3 — Fair A40 eager profile

**Runs:** PGCF-005.

Batch1/L16/BF16/1000 timed iterations; report complete and incremental p50/p90/mean, memory, projected table, same eager/compiled state.

**GO:** complete PGCF `<=1.20×` complete released Domino. If not, only semantics-preserving kernel fusion/preprojection or a predeclared smaller d/layer configuration may be tested; every change repeats capacity and profile.

### G4 — Small disjoint global-use screen

**Runs:** PGCF-006 global seed0; PGCF-007 local seed0; PGCF-008 remote intervention. Seeds1/2 confirmation only if seed0 gate passes.

**GO:** C2 thresholds exactly as Section1. Also require train and heldout fit diagnostics:

- train high / heldout flat => transfer failure, no parameter increase;
- train and heldout both underfit => one conditional d384/L2 branch allowed, exact params/profile required;
- global signal absent => close mechanism, do not drift off-spec.

### G5 — Full16 OPB collection

**Runs:** PGCF-009 array tasks0–3.

Each task recollects one selected OPB shard with max6,250 prompts. Required rows: `H[16]`, pure baseTop16 IDs/logits, gold16, policy16/support, target candidate logits16×16, target top1, anchor/context identifiers. Explicitly reject early target features and L15 tensors.

**GO:** combined approximately25K prompts/~199.8K blocks; D3/D4/D2 sample+anchor overlap zero; position15 populated; released/base/oracle evaluator identities match fixed references on D2.

### G6 — Stage-A full16 curriculum

**Runs:** PGCF-010 seed0 primary; PGCF-011 no-teacher diagnostic only after primary result if needed.

- first10% teacher-only; 10–30% fixed linear transition; remaining target-only;
- checkpoint by D2 prompt-balanced EAL, earliest exact tie;
- teacher-only snapshot EAL≥7.080272109;
- final Stage-A EAL≥7.55, above Domino, every domain≥base.

**GO:** proceed to three-seed mixed adaptation. **NO-GO:** diagnose label alignment, fit and representation; no system polishing.

### G7 — Mixed adaptation and development freeze

**Runs:** PGCF-012/013/014 seeds0/1/2.

Mix D3:D4 at3:1, target-only low-LR, frozen DFlash. Per seed choose max D2 EAL/earliest tie. Pre-formal primary is highest D2 EAL; ties lower seed then earlier step.

**GO:** primary D2 fixed EAL≥8.325485909; each domain≥same-job Domino domain−0.05. Freeze model, recipe, evaluator, formal row rule, dynamic generation and same-job commands.

### G8 — One-shot formal fixed and dynamic

**Runs:** PGCF-015 receipt/collection; PGCF-016 fixed; PGCF-017 dynamic.

- primary selected pre-formal;
- fixed overall≥1.15× Domino;
- each formal domain PGCF≥Domino point estimate;
- dynamic overall≥1.15× Domino;
- all three frozen seeds reported as sensitivity without changing primary.

Formal failure makes D5 development-only permanently.

### G9 — Same-stack SGLang

**Runs:** PGCF-018 integration smoke; PGCF-019 paired A40 performance.

One draft backbone instance, preprojected table, full16 global head, normal single-chain verifier. Compare same batch/workload/backend/precision/graph policy.

**GO:** TPS ratio≥1.15 and accepted length remains above Domino. Report median/p90 latency, TPS, EAL, memory.

## 5. Checkpoint and statistics
