## Localized filesystem cause

probe in the same filesystem reproduced the exact primitive failure on an
empty directory:


In that same probe, ordinary same-filesystem directory rename succeeded,
exclusive `mkdir` succeeded and rejected an existing name, and a same-directory
hard link succeeded and rejected an existing commit name. The latter two
operations therefore remain candidates for a GPFS-compatible no-clobber
commit protocol, but no implementation change is authorized by this diagnosis.
