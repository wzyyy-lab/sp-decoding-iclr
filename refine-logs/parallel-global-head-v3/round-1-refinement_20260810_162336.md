# Round 1 Refinement：PCLD-16R — Parallel Clean Predictive-Residual Distillation

> 状态：针对 Round 1 的三个 blocker 完成方法级修订；尚未授权实现或 GPU 实验。  
> 结论边界：这是一次完整 16 位、全局非因果、单次并行、唯一单链的 head。离线 target hidden 只作监督，线上不增加 target forward。

## Problem Anchor（保持不变）

- **Bottom-line problem：** 在不改变 DFlash 一次并行生成整块这一核心优势的前提下，设计一个轻量 head，显著解决 accepted length 偏低的问题；固定与动态 EAL 都至少达到同作业 released Domino 的 `1.15x`，最终同栈 SGLang 端到端吞吐也至少达到 Domino 的 `1.15x`。
- **Must-solve bottleneck：** 当前 full16 disjoint development 上，DFlash base EAL 为 `6.0685131195`，released Domino 为 `7.2395529640`，目标为 `8.3254859086`，pure-base Top16 oracle 为 `10.90925656`。JAPD-v2 的 D256/H8/L2 global head 已证明延迟不是主瓶颈（完整 eager head 为 Domino 的 `0.9993x`，新增参数 `4.54M`），并能在 512-block capacity set 上达到 `99.8627%` candidate accuracy、`99.7033%` hard accuracy、`94.2090%` oracle-gap recovery，但仅 6 个 harmful blocks 就使 EAL/harm 硬门失败；在 512 个完整 prompt 的同集 full-fit 上仍只有 `5.5133%` recovery、`24.6136%` J2 和 `18.1641%` harm。PGCF/JAPD 两代 frozen-feature global selector 因此共同表明：Top16 覆盖、head 延迟和单块记忆容量都足够，真正未解决的是 frozen DFlash 表示对 clean parallel trajectory 的跨-prompt 可辨识性，以及平均 candidate loss 无法控制少数 early-prefix mistakes 的尾部风险。新方案必须在保持一次 full16 全局并行单链推理的同时改变这一信息/优化条件，而不能继续只扩 selector 或调同一 loss。
- **Non-goals：** 不做 Domino/GRU 式自回归，不做 selected-token feedback，不做串行 target seed/decode，不做 Jacobi 或任何迭代 refinement，不做 beam/tree/trie/forest/multipath，不让 Top16 变成路径维，不增加 ordinary verifier 之外的在线 target inference，不把 D512、同一 JAPD loss 调权或 schedule sweep 当作补救，也不在 accepted-length 主机制成立前投入 SGLang 小修小补。
- **Constraints：** 单次 head 必须同时消费完整 `[B,16,*]` DFlash online features；每个输出位置必须通过无 causal mask 的全局 mixer 看到全部16位；一次产生 `[B,16,16]` scores 并以一次逐位置 argmax 得到唯一 `[B,16]` 序列。Top16 只作每位置候选轴。在线只能复用正常 DFlash/target-prefix 特征，target clean continuation 只作离线监督；不得增加 draft/head/target 的位置循环或二次调用。新增在线参数原则上不超过 `10.75M`，训练时允许改变 DFlash 表示的方案必须在部署前合并、不得增加推理层数或 forward 次数，并以同 A40、同 BF16、同 batch/block、eager-to-eager 公平 profile 约束成本。
- **Success condition：** 在严格 disjoint prompt 上证明 full16 global head 的跨-prompt机制增益，fixed EAL 至少 `8.3254859086`，dynamic EAL 至少同作业 Domino 的 `1.15x`，三个域均不退化；随后同栈 SGLang A40 tokens/s 的 paired 95% CI 下界至少 `1.15x` Domino。任何架构不变量失败、仅 same-set capacity 成功、仅 oracle 成功、或使用串行/迭代/多路径结果，都不能替代该成功条件。

## 1. Round 1 blockers 与关闭方式

| Round 1 blocker | 修订 |
|---|---|
| Domino-code 公式在零初始化时仍留下非零 correction，不能精确回退 DFlash | 完全删除 Domino `prefix_gru/W_h/W_s/W_out`。新 head 只预测 target-hidden residual；输出层 `U=0` 时 correction 严格为零 |
| 对 `W_s s_i` 的方向归一化回归丢失幅值，且“sufficient statistic”表述过强 | teacher 改为 `Delta_i^*=T_i-H_i`；使用训练集固定逐维尺度的保幅 Huber，并报告 raw hidden 与 candidate-logit fidelity；不再声称统计充分性 |
| 原 log-sum-exp margin loss可趋向负无穷，也不是 certificate | 改成带 `1+\sum`、下界为零的 smooth worst-prefix risk；最终安全证据只来自 untouched prompt 的 harm/gain-loss/bootstrap CI |

同时删除 continuous gate、JAPD exposure audit 和三套 Domino/target/code teacher。主方法只保留一个 residual teacher、一个全局 student、一个匹配的 no-latent control。

## 2. 精确的 full16 teacher geometry

令 ordinary DFlash 一次产生经过其最终 norm、送入共享 target LM head 之前的

\[
H\in\mathbb{R}^{B\times16\times d_t},\qquad d_t=2560.
\]

离线 clean target continuation 为 \(y_0,\ldots,y_{15}\)。对 target model 做一次 teacher-forced pass：

\[
[\text{context},\text{anchor},y_0,\ldots,y_{14}].
\]

取 final-norm 后的 16 个 predictive rows：

\[
T_i=\operatorname{TargetHidden}(\text{anchor},y_0,\ldots,y_{i-1}),\quad i=0,\ldots,15.
\]

因此 row 0 消费 anchor 后预测 \(y_0\)，row 15 消费 \(y_{14}\) 后预测 \(y_{15}\)。监督为

\[
\Delta_i^*=T_i-H_i.
\]

这 16 行在 GPU materialization 前必须由两套独立路径锁死：

1. 单次 batched teacher-forced target 与 16 次离线手工 cached recurrence 的逐行 hidden/candidate-logit parity；
2. 明确断言 row 0、row 15、label shift 和完整 16-token reconstruction。

这只是离线数据正确性检查，不进入 production，也不授权串行在线 target decode。

## 3. Online architecture

### 3.1 唯一在线输入与输出

一次 ordinary DFlash forward 后已有：

- \(H[B,16,2560]\)；
- pure-base full-vocabulary logits \(Z\)；
- 由 \(\operatorname{Top16}(Z.float())\) 得到的 candidate IDs \(C[B,16,16]\) 和 base candidate scores \(B[B,16,16]\)；
- 同一冻结 LM-head/embedding table 的 candidate rows \(e_{ik}=E[C_{ik}]\)；
- anchor、position/rank 和只由 base logits 得到的 5 个标量特征。

head 一次返回 \(S[B,16,16]\)。唯一 proposal 是

\[
\hat y_i=C_{i,\arg\max_k S_{ik}},\quad i=0,\ldots,15.
\]

16 个 argmax 是同一个 tensor operation；任何已选择 token 都不再进入 head。

### 3.2 256-node global noncausal mixer

每个位置/候选形成一个 node：

\[
x_{ik}=W_H\operatorname{RMS}(H_i)+W_E\operatorname{RMS}(e_{ik})
+W_f f_{ik}+p_i+r_k.
\]

全部 \(16\times16=256\) nodes 进入两层 D256/H8 的 flat self-attention，attention mask 固定为 `None`，任意 node 都能看见其他 255 个 node。随后 16 个 learned position queries 分别 cross-attend 同一组完整 256 nodes，得到

\[
g_i\in\mathbb{R}^{256}.
\]

这里没有 causal/local production 模式、pool-first mode compression、位置循环或路径维。parameter-matched local mask 只存在于离线 ablation。

### 3.3 Predictive residual 与 exact score identity

唯一新 residual：

\[
\widehat{\Delta}_i=Ug_i\in\mathbb{R}^{2560},
\]

其中 \(U\) 的 weight 与 bias 均严格 zero-init。在线 candidate score：

\[
S_{ik}=B_{ik}+\langle e_{ik},\widehat{\Delta}_i\rangle.
\]

共享、无 bias 的冻结 target LM head 给出两个可验证性质。

**Property 1 — exact step-0 identity**

\[
U=0\Longrightarrow S_{ik}=B_{ik}.
\]

所以 rank-0 candidate 必须逐 token 等于 pure DFlash top-1；不是“近似回退”。

**Property 2 — exact teacher score reconstruction**

若 \(\widehat{\Delta}_i=T_i-H_i\)，则

\[
B_{ik}+\langle e_{ik},T_i-H_i\rangle
=\langle e_{ik},T_i\rangle.
\]

它只证明 candidate score 的代数恒等，不证明 residual 低秩、可预测或能跨 prompt 泛化；后三项是实验假设。

### 3.4 参数与 latency 边界

初版固定 D256/H8/L2。主要新增参数约为：

- \(W_H,W_E\)：约 1.31M；
- 两层 full-node transformer：约 1.58M；
- 一次 16-query cross-attention：约 0.27M；
- \(U:256\rightarrow2560\)：约 0.66M；
- scalar/position/rank/norm/bias：低于 0.1M。

预期总量约 3.9M；实现必须给 exact count，hard stop 为 5.0M，且绝不超过用户上限 10.75M。冻结 LM-head rows 是 DFlash/target 已有共享权重，不重复计为新增参数。

完整 eager profile 必须计入 base vocab GEMM、FP32 Top16、candidate gather、所有 global layers、residual candidate dot、argmax/gather；与相同 hidden/weight/BF16/batch1/B16 的 released eager Domino 比较。development 上保守门仍为 complete p50 \(\le1.20\times\) Domino，而最终只以同栈 SGLang TPS 为准。

## 4. Offline teacher ceiling 与数据边界

先构造 exact teacher candidate scores

\[
S^*_{ik}=B_{ik}+\langle e_{ik},T_i-H_i\rangle.
\]

它必须与直接用 \(T_i\) 和同一 candidate row 做 FP32 dot 的结果数值一致；另报告它与 target 原生 LM-head GEMM 在 stable non-tie rows 的 top-1 parity。stored canonical gold 不能覆盖 clean target authority。

P0 teacher ceiling 必须报告：

- 16-row score/selected-token parity，position 0/15 单列；
- pure-base Top16 support、clean horizon 与完整 verifier EAL；
- 相对 base 的 gain/loss/harm 与三个域；
- teacher candidate EAL 至少 9.0，且其 oracle headroom 足以越过主目标 8.3254859086。

若 exact residual teacher 本身过不了该 ceiling，路线直接关闭。teacher ceiling 不是 deployable result。

现有 R047 validation-select 的只读 pure-base Top16 audit 已给出一个有利但非最终的
development ceiling：teacher EAL 10.5971817298、Domino 7.2395529640、
gold-aware oracle 10.9092565598，906 gain / 3 loss / 266 tie，harm 0.2553%，
三个域均提高。完整数字见
PCLD_TEACHER_CEILING_AUDIT_20260810_163405.md。这只关闭 teacher headroom，
不关闭 residual rank、在线可预测性或 transfer 风险。

所有 target hidden、clean token、target logits和 \(\Delta^*\) 都由训练/评估 sidecar 持有，production batch schema 必须 fail-closed 拒绝这些字段。

## 5. Training objective

### 5.1 保幅 latent loss

只在 training split 上预计算每维尺度

\[
q_j=\max(\operatorname{Std}_{train}(\Delta^*_{:,j}),10^{-3}),
\]

然后冻结。clean-support mask \(M\) 内：

\[
L_{\mathrm{latent}}
=\frac{1}{|M|d_t}\sum_{(b,i)\in M,j}
\operatorname{SmoothL1}\left(
\frac{\widehat{\Delta}_{bij}-\Delta^*_{bij}}{q_j}
\right).
\]

不得使用逐样本 RMS direction-only loss。训练与评估同时报告 raw residual RMSE、whitened RMSE、candidate correction-logit RMSE、candidate KL、teacher-margin sign/agreement；cosine 仅作诊断。

### 5.2 有下界的 smooth worst-prefix risk

令 clean target token 在 candidate axis 的 rank 为 \(r_{bi}\)，并只在连续 clean-support prefix \(i<h_b\) 上定义 normalized margin

\[
\widetilde m_{bi}=
\frac{S_{bi,r_{bi}}-\max_{k\ne r_{bi}}S_{bik}}
{\max(\operatorname{Std}(B_{bi,:}),0.25)}.
\]

固定 early-utility 权重 \(w_i=(16-i)/16\)，使用

\[
L_{\mathrm{safe}}^{(b)}
=\tau\log\left[
1+\sum_{i<h_b}w_i
\exp\left(\frac{\gamma-\widetilde m_{bi}}{\tau}\right)
\right],
\]

其中 \(\gamma=0.1,\tau=0.1\)。该 loss 非负、有下界、显式提高早位错误权重，但只称 surrogate risk。

### 5.3 单一 teacher distribution

用 \(S^*\) 定义同一个 Top16 target distribution：

\[
L_{\mathrm{targetKL}}=
\operatorname{KL}(\operatorname{softmax}(S^*)\|
\operatorname{softmax}(S)).
\]

总目标固定为

\[
L=L_{\mathrm{safe}}+\alpha(t)L_{\mathrm{latent}}+0.1L_{\mathrm{targetKL}},
\]

\(\alpha(t)\) 在前 30% updates 从 1.0 线性降到 0.1，之后为 0.1。不做权重 grid。matched no-latent control 使用完全相同架构、数据、更新和 \(L_{\mathrm{safe}}+0.1L_{\mathrm{targetKL}}\)，只令 \(\alpha=0\)。

不使用 continuous gate、阈值后处理、第二 expert、per-domain calibration 或 Domino teacher。

## 6. 最小、逐级授权的 falsification plan

### P0 — mechanics、teacher ceiling、complete latency

必须全部通过：

1. full16 batched/manual teacher geometry parity，position 15 单独覆盖；
2. step0 pure-DFlash 16-token identity mismatch 为 0；
3. remote-position intervention 能改变任意远端 output，local/causal production scope hard fail；
4. exact residual score parity与 teacher ceiling EAL \(\ge9.0\)；
5. exact trainable parameter \(\le5.0M\)；
6. A40 complete eager p50 \(\le1.20\times\) released eager Domino。

可额外报告 train-only rank-256 PCA 对 hidden residual 的谱能量与 candidate-logit
重建，但它只是一项 latent diagnostic，不能作为结构性 STOP gate。普通 PCA
最小化 hidden L2，并不是 candidate-score 最优子空间；而动态 candidate matrix
\(A_i\in\mathbb{R}^{16\times2560}\) 在 \(A_iU\) 满 row-rank 时，oracle
\(g_i\in\mathbb{R}^{256}\) 原则上可以表示任意 16 维 candidate correction。
真正的 hard question 是 online lattice 能否跨 prompt 预测 \(g_i\)，只能由
matched disjoint student experiment 回答。

### P1 — 512-block same-set capacity（只证 mechanics/optimization）

D256/H8/L2、8,000 updates、单一固定 recipe。必须同时满足：

- teacher candidate argmax agreement \(\ge99\%\)；
- normalized latent RMSE \(\le0.25\)，并完整报告 raw/candidate-logit error；
- oracle-gap recovery \(\ge95\%\)；
- harm \(\le1\%\)；
- strict multi-repair/J2 \(\ge99\%\)。

失败只允许修 indexing、precision 或已证 optimizer bug；不加 D512、不扫 loss/schedule。

### P2 — 三 seed cross-fitted mechanism gate

使用冻结的 R047 prompt split：1589 train / 199 internal-select / 199 untouched diagnostic。global、parameter-matched local-mask、matched no-latent 三个 arm 各跑 seeds 0/1/2；数据顺序、updates、optimizer与 checkpoint cadence一致。architecture/hyperparameters 只看 train/select 冻结，diagnostic 三个 arm 同时一次性打开。

GO 必须全部满足：

- 每个 global seed diagnostic EAL \(\ge base+0.30\)；
- seed-aggregated global-local EAL \(\ge0.15\)，prompt-paired bootstrap 95% CI lower \(>0\)；
- seed-aggregated global–no-latent EAL \(\ge0.15\)，95% CI lower \(>0\)；
- 每 seed harm \(\le1\%\)；
- oracle-gap recovery \(\ge20\%\)，strict J2 \(\ge40\%\)；
- chat/code/math各域不低于 pure base。

P2 失败表示 clean predictive residual 或 full-block global context没有跨 prompt 机制证据，路线关闭；不能靠扩大宽度、延长 exact recipe 或改成 causal/tree补救。

### P3 — 条件性 25K / 100K scaling

只有 P2 GO 才重采 strict full16 OPB 25K prompts（约 200K blocks），sidecar 可被三 seed 共享。25K development 必须同时：

- held-out fixed EAL \(\ge7.8\)；
- global-local 与 global–no-latent 保持正向且预注册 CI 下界 \(>0\)；
- 三域不退化；
- 相比 P2 数据规模的 held-out EAL 有正斜率。

仅 train loss下降不能授权 100K。只有上述全部通过，且 25K 未饱和，才扩到 100K prompts。25K EAL \(<7.55\) 或 causal controls无信号则直接关闭。

### P4 — claim-bearing efficacy 与 systems

architecture、weights、checkpoint、kernel和任何 calibration 全部冻结后顺序打开：

1. sealed fixed prompts：EAL \(\ge1.15\times\) same-job Domino（当前 development 数字仅作参考，主门约 8.3254859086），三域不退；
2. fresh dynamic rollout：EAL \(\ge1.15\times\) same-job dynamic Domino；
3. 同 SGLang 栈、A40 batch1、paired prompt workload：TPS ratio 的 95% CI lower \(\ge1.15\)。

accepted length不过门时不做系统小修；efficacy 过而 TPS不过时才允许 kernel/fusion 优化，且不能改变 token semantics。

## 7. 最少必要 controls 与贡献边界

只保留：

1. pure DFlash；
2. released Domino；
3. PCLD-16R global；
4. parameter-matched local mask；
5. matched no-latent/KL-only。

不再运行 JAPD exposure rescue，不做 Domino-code teacher、不做 head width/layer/loss grid。

若实验成功，可主张的范围仅为：

> 在 pure-base Top16 candidate lattice 上，将 16 个 clean autoregressive predictive-hidden residual 蒸馏到一个 candidate-conditioned、full-block noncausal student；该 student 一次并行产生唯一 16-token proposal，并通过 matched controls 证明 global block context 与 latent residual supervision 对 held-out acceptance 都有因果增益。

不声称 predictive-latent alignment、attention、Top16、distillation 或 margin loss本身新颖；也不使用“统计 sufficient statistic”或“形式化 safety certificate”。相对 Your LLM Knows the Future 的新增只能是 speculative-decoding 的 full16 candidate-conditioned one-chain formulation、accepted-prefix risk和系统证据。

## 8. 最高风险假设与最便宜证伪

1. \(T-H\) 在候选相关子空间里可由 full16 DFlash lattice 跨 prompt 预测，而非只可同集记忆；
2. hidden-residual supervision相对 matched candidate-KL 提供独立 transfer；
3. 全局非因果远端信息相对 parameter-matched local head提供可重复增益；
4. smooth worst-prefix risk能把 early harm 压至 1% 而不牺牲 repair；
5. 约 4M head 的 complete latency在最终 accepted-length增益下仍保留 1.15x SGLang TPS。

P0 证伪 teacher/geometry/cost，P1 证伪实现与容量，P2 同时证伪 1–4，P3/P4 才检验可扩展性和系统价值。任何失败都留在用户合同内停止，不再回到串行、迭代或多路径。
