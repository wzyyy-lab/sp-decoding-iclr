# Final Proposal: Safe Global Full-Lattice Reranking for Frozen DFlash

**Date:** 2026-08-04  
**Status:** Method frozen for staged experiments  
**External review:** 8.05/10; experiment GO after completed preflight

## Problem Anchor

在 Qwen3-4B / DFlash-b16 的 greedy speculative decoding 中，DFlash 一次前向已经生成 15 个 draft positions、每位置 top-16 的候选格点，但原始解码只在每个位置独立选择 rank-1。目标是在不修改 target、released DFlash 或 verifier，不引入 tree verification 和顺序 GRU 的前提下，从这份已生成的格点中选出一条更长的真实可接受单链，并最终获得正吞吐收益。

现有 GCLS-v1 已证明 global evidence 有效：三 seed 平均相对 DFlash 的 calibrated EAL 为 `+0.232`，global−local 为 `+0.172`、global−causal 为 `+0.087`，prompt-cluster CI 均排除 0。但最佳 checkpoint 只修复 18.3% first-miss opportunities，伤害 7.3% blocks，只回收约 6.2% 的 K16 oracle gap；与同 anchor Domino on-policy 仍差约 1.62 EAL。

## Root-Cause Diagnosis

旧方案效果受限于四个相互关联的问题：

1. **候选信息过早损失。** axial mixer 在跨位置交互前，把每个远端位置的 16 个候选压成一个 DFlash 加权均值；global 层看不到“哪个候选与当前上下文兼容”。
2. **交互表达不足。** hidden、candidate embedding 和 anchor embedding 主要是加法融合，没有显式的 candidate–context 或 anchor–candidate 乘性交互。
3. **目标与 greedy utility 不完全对齐。** 训练活跃前缀平均覆盖 9.72 positions/block，而当前策略的真实 greedy reach+breaker 只有 6.21；约 36.1% 的活跃位置在当前 breaker 之后。普通 candidate accuracy 也不是 utility：同一 checkpoint 的 local mask non-top1 accuracy 更高，EAL 却比 DFlash 低约 0.80。
4. **强基线缺少非对称保护。** 全局纠错既能修复 first miss，也能翻转原本正确的 DFlash prefix；旧损失未按 block 平衡地保护后者。

## Method Thesis

> 对 frozen DFlash，先保留完整候选假设再做全局交互，用 candidate-support 上的 unsmoothed accepted-reach gradient 训练 base-anchored residual selector，并对 DFlash 原 accepted prefix 施加 block-balanced margin regularization，可提高净 EAL，同时避免依赖顺序 causal head。

这不是“新 accepted-length loss”的主张。Accepted-reach 与 length-normalized Candidate-D-PACE `alpha=0`、detached weights 在相同 support 下具有完全相同的参数梯度；代码用单测固定这一等价性。贡献边界只包括 frozen top-K residual-selector 场景、candidate-support censoring、no-prepool global interface，以及 frozen strong base 的非对称保护。

## Frozen Implementation Contract

### Inputs and invariants

- 一个 block 含固定 `L=15` 个 draft positions，`K=16`，无 padding。
- candidate index 0 是 canonical collection 在 float32 DFlash logits 上记录的 rank-1 action。新 collection 同时存储 `argmax` witness，并断言它等于 `topk[...,0]`；collate 对带 witness 的记录再次断言。
- 输入仅含 frozen DFlash hidden、candidate IDs/logits、full-vocabulary logsumexp、anchor ID 和 frozen Qwen3 target embeddings。
- candidate/gold 安全 gather：gold-not-in-K 时先夹到合法 index，再由 availability 置零，不访问非法 index，不显式计算 `log(0)`。
- epoch 0 residual readout 为零，完整 score tensor 与 canonical DFlash log-probs 相同，greedy path 全部为 candidate 0。

### Scalar features

所有计算为 float32，通道顺序固定为：

1. full-vocabulary log probability，`tanh(log_p_full / 8)`；
2. renormalized top-K conditional log probability，`tanh(log_p_K / 8)`；
3. 非负 top-1 gap，`tanh((logit_0-logit_k)/8)`；
4. retained full-vocabulary log mass，`tanh((logsumexp(topK)-logsumexp(full))/2)`；
5. renormalized top-K entropy，除以 `log K` 后 clip 到 `[0,1]`。

五个通道经 `5→D→D` MLP 投影，不改变最终使用的原始 DFlash base log-probs。

### Candidate-context nodes

hidden 使用无 affine LayerNorm 与独立 projection；candidate 与 anchor embeddings 共享无 affine LayerNorm 和 token projection。兼容性节点为：

```text
c_ik = MLP_4D_to_2D_to_D([h_i, e_ik, h_i * e_ik, a * e_ik])
z_ik = LN(c_ik + position_i + rank_k + scalar_MLP(phi_ik))
```

没有 trainable vocabulary table。

### Compact full-lattice mixer

主模型固定为 flat、global、`D=128`、8 heads、2 个 pre-norm self-attention blocks、FF multiplier 4、dropout 0，共 1,235,808 参数。全部 `15×16=240` nodes 保留到 readout。每层含一个可训练的 per-head relative-position bias table（`2L-1` 个相对位置，零初始化），以及一个可训练的 per-head same-position group bias（初始化为 `log L`）。后者补偿每个 query 面对 `K` 个同位置 nodes 和 `(L-1)K` 个远端 nodes 的组大小差异；在 local mask 下它是所有合法 keys 的共同 offset，严格抵消。两种 bias 是冻结实现的一部分而非 novelty claim。

local/causal/global 对照只改变 visibility mask，包含相同的 bias 参数、参数量与初始化。scope 隔离通过扰动测试定义：改变其他位置不能影响 local 输出；改变未来位置不能影响 causal 的早期输出；同一扰动应能影响 global 输出。

### Base-anchored scores

```text
s_ik = log p_DFlash(C_ik) + Delta_ik
```

readout 零初始化；每位置共同 residual offset 被消除。部署使用 `argmax`；精确 tie 由最低 candidate index 保留 base。

### Accepted-reach utility

```text
q_i = availability_i * softmax(s_i)[safe_gold_i]
S_t = product_{i<=t} q_i
U = sum_t S_t
L_reach = 1 - mean(U / 15)
```

首次 gold-not-in-K 会令该位置和整个 suffix 的 survival 为零。对 batch 内有效位置：

```text
d L_reach / d(-log q_bi) = (1 / (B*15)) * sum_{t>=i} S_bt
```

`log_softmax`、gold probability、prefix product 和 utility 强制使用 float32，即使主网络在 bf16 autocast 下训练。

### Block-balanced base-prefix regularizer

对每个 block，`b_i` 是从 position 1 起 DFlash 连续 rank-1 正确的 accepted-prefix mask，固定 margin `m=0.1`：

```text
R_block = mean_{i:b_i=1} relu(0.1 + max_{k>0}s_ik - s_i0)
R_block = 0 if the base prefix is empty
L = L_reach + lambda * mean_blocks(R_block)
```

它是 regularizer，不是 5% harm 保证。development 只比较 `lambda∈{0,0.1,0.25}`。raw model 是主方法；KEEP_BASE threshold 是单独校准并明确标注的 deployment variant。

## Staged Validation

1. **CPU deterministic gate:** scalar definitions、manual utility、ARR/CDP gradient parity、float32 reach、identity init、scope perturbation、frozen inputs、sorted/witnessed rank-1。
2. **GPU smoke:** compact compatibility model，global/reach/`lambda=0.1`，128 same-subset blocks，5 epochs；只验证 kernel、metrics 和 artifact。
3. **128-block capacity gate:** 同架构与目标，120 epochs，`lambda={0,0.1,0.25}`；至少一个配置同时达到 candidate accuracy ≥99%、non-top1 accuracy ≥97%、first-miss repair ≥95%、oracle-gap recovery ≥95%、harm ≤1%，才进入大数据筛选。每个任务只负责完整落盘，数组后由聚合器执行“至少一个通过”的 stage gate；缺失/损坏 artifact 与科学阴性使用不同退出码。capacity checkpoint selection 优先保留任何完整 gate-passing epoch，再按 EAL tie-break。
4. **Objective isolation:** 固定 current axial-additive architecture，比 historical smoothed D-PACE `alpha=.5`、unsmoothed reach、reach+margin。
5. **Representation isolation:** 固定 selected reach+margin，比 axial single-mean、flat additive、flat compatibility。
6. **Scope confirmation:** 对胜出 representation 做 matched local/causal/global，三 seeds 和 prompt-cluster bootstrap。
7. **Positive-only capacity probe:** 仅在 compact route 仍明显低于目标时，用 `D=640`、10 heads、4 layers、27,482,160 参数，复用已选 objective/`lambda`；高结果是 sufficiency witness，低结果只是工程 stop。
8. **Latency/throughput:** 只有 raw EAL 通过后才集成真实 DFlash path，测 head latency、break-even 和端到端 TPS。

## Decision Rules

- capacity gate 失败：先读日志并修实现；若实现正确仍失败，停止 full-data 训练。
- reach+margin 不优于 historical smoothed D-PACE：删除 objective/safety adaptation claim。
- flat compatibility 不优于 axial：删除 full-lattice representation claim，不追加 slot/CRF/GRU rescue。
- global 不优于 matched causal/local：删除 global-evidence claim。
- raw EAL 为正但 latency 后 TPS 不为正：只保留 selector 结果，不声称 decoding-system improvement。
- positive probe 高而 compact 低：允许一次 distillation/压缩项目；probe 低不支持“输入无信息”结论。
- frozen route仍显著落后 Domino：如实归因 joint backbone、causal prefix 或 data confound；LoRA 另立研究问题。

## Success Criteria

Development 进入 confirmatory 的最低条件为：相对 DFlash raw EAL 明显优于现有最佳 `+0.285`，first-miss repair 提升且 harmed fraction 下降；full-lattice global 同时优于 parameter-matched axial、local、causal。最终 claim 需要三 seeds、一致方向、prompt-cluster CI 排除 0、独立 test 上 harm 的单侧 95% 上界不高于 5%，以及正端到端吞吐收益。

## Novelty and Non-goals

不声称 self-attention、multiplicative compatibility、expected-prefix loss、candidate lattice 或 margin regularization 单独新颖；不把 K16 oracle 当可实现收益；不使用 tree verification、顺序 GRU、在线 teacher 或 RL；首轮不声称 sampling `T>0` lossless。论文是否成立完全取决于 coupled design 能否产生轴向/局部/因果对照解释不了的稳定收益。
