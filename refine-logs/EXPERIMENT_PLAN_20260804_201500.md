# Experiment Plan

**Problem:** Frozen DFlash 的完整 top-K lattice 含有可利用的跨位置信息，但旧 GCLS 的候选预池化、弱 candidate-context 交互和未保护 base prefix 的训练只带来约 +0.232 calibrated EAL。  
**Method Thesis:** 保留完整候选格点的 global compatibility reranker，配合 candidate-support accepted-reach training 与 block-balanced base-prefix regularizer，能比 axial/local/causal controls 获得更高的净 accepted length。  
**Date:** 2026-08-04

## Claim Map

| Claim | Why It Matters | Minimum Convincing Evidence | Linked Blocks |
|---|---|---|---|
| C1：完整候选格点上的 global compatibility interaction 是增益主因 | 这是区别于旧 axial mean pooling 和普通 local reranking 的核心 | flat-compat global 在 matched budget 下优于 axial、flat-additive、causal、local；prompt-cluster CI 排除 0 | B2, B3 |
| C2：unsmoothed reach + base-prefix regularization 改善 repair/harm 净效用 | 仅提升 candidate accuracy 或 repair 而破坏 base 不足以解决问题 | 相对 historical D-PACE α=.5，raw EAL 提升、first-miss repair 上升、harm 下降；独立 test harm UCB≤5% | B1, B2, B4 |
| Anti-claim：收益只来自更多参数、同一 validation 上校准或扩大搜索空间 | 这些是最直接的替代解释 | 参数匹配 scopes、axial/flat controls、raw 与 KEEP_BASE 分列、相同 K16 与 verifier | B2, B3, B4 |

## Paper Storyline

- Main paper must prove：完整 lattice 的 global compatibility interaction 在 frozen DFlash 上产生 axial/local/causal 无法解释的 raw EAL 与吞吐增益，并且 base harm 可控。
- Appendix can support：positive-only high-capacity probe、feature replacement、domain breakdown、校准曲线、failure cases。
- Experiments intentionally cut：ARR 与 normalized Candidate-D-PACE α=0 的重复训练；slot compression；CRF/Viterbi；默认 distillation；RL；tree verification。
- Frontier component：只使用对 frozen foundation-model features 的 compact full-lattice attention；无需强行加入 LLM judge、RL 或 diffusion。

## Experiment Blocks

### Block 0: Deterministic and GPU Preflight

- Claim tested：实现是否忠实于 frozen method contract。
- Why：先排除错误 loss、support、scope mask、mixed-precision underflow 和环境问题。
- Dataset / split：CPU synthetic fixtures；GPU 为 canonical train split 的固定 128-block same-subset。
- Compared systems：epoch-zero identity；flat compatibility global/reach/λ=.1。
- Metrics：39 项 targeted unit tests；finite loss/gradient；完整 output artifact；GPU witness；peak memory。
- Setup：D128/H8/L2/flat/compatibility/global，K16，batch16，AdamW lr6e-4、wd0、warmup .04、clip1，5 epochs。每个 flat block 使用零初始化的 trainable per-head relative-position bias，以及初始化为 `log L` 的 trainable same-position group bias；所有 scopes 参数匹配。
- Success criterion：CPU tests 全过；GPU 无 NaN/OOM；metrics.json 存在；epoch0 与 canonical base score/path 一致。
- Failure interpretation：实现或环境问题；不得进入 full-data。
- Target：artifact/appendix reproducibility note。
- Priority：MUST-RUN。

### Block 1: Objective and Safety Isolation

- Claim tested：unsmoothed accepted reach 与 base regularizer 是否改善净 utility。
- Why：旧 D-PACE α=.5 会对当前 breaker 后的 position 平滑分配权重，且没有非对称 base 保护。
- Dataset / split：Open-PerfectBlend 100K canonical 的 nested 25K prompt train subset；原 Phase-3 `validation_select`，不读取 `validation_gate` 或 reserved test。
- Compared systems（固定旧 axial-additive D64/H4/L1/global）：
  1. historical D-PACE α=.5、λ=0；
  2. accepted reach、λ=0；
  3. accepted reach、λ=.1；
  4. accepted reach、λ=.25。
- Metrics：primary raw prompt-balanced EAL delta；secondary first-miss repair、harmed fraction、first-token accuracy、minimum-domain delta、soft-U/greedy-EAL epoch correlation。KEEP_BASE 只作分列的 calibration diagnostic。
- Setup：K16，batch64，9 epochs，lr6e-4，3 seeds 仅对胜出配置补跑；screen 先 seed0。
- Success criterion：selected reach condition raw EAL 高于 historical baseline，且不是以更高 harm/首 token 下降换取；λ 由预定义 lexicographic rule 选择：raw EAL、harm、minimum-domain、first-token。
- Failure interpretation：若 reach 不胜，删除 objective adaptation；若 λ 均无益，λ=0 并删除 safety-training claim。
- Target：main ablation table。
- Priority：MUST-RUN。

### Block 2: Representation Isolation

- Claim tested：no-prepool candidate hypotheses 与 multiplicative compatibility 是 global gain 所必需。
- Dataset / split：与 B1 同一 nested 25K train 和 validation_select；使用 B1 冻结的 objective/λ。
- Compared systems：
  1. axial single-summary additive D64/H4/L1；
  2. flat full-lattice additive D128/H8/L2；
  3. flat full-lattice compatibility D128/H8/L2。
- Metrics：raw prompt-balanced EAL、repair/harm、oracle-gap recovery、参数、peak memory、head latency。
- Setup：global、K16、seed0 screen；胜者再跑 seeds 1/2。参数差异明确报告，另以 scope-matched controls排除“只因参数更多”。
- Success criterion：flat compatibility 明显优于 axial 且至少不劣于 flat additive；若仅参数更大的条件提升，则补一个 width-matched axial control。
- Failure interpretation：flat 不胜 axial则删除 architecture claim并停止追加复杂组件；compatibility 不胜 additive则删除 compatibility MLP。
- Target：main representation ablation。
- Priority：MUST-RUN。

### Block 3: Matched Scope and Confirmatory Result

- Claim tested：收益来自非因果远端格点证据，而不是本位置/过去信息或 seed 偶然性。
- Dataset / split：冻结 train manifest；独立 calibration、untouched test，prompt-disjoint。正式划分前先用 pilot 估计 cluster design effect；保守预留 ≥1,000 calibration、≥2,000 test prompts。
- Compared systems：DFlash；historical GCLS-v1 axial global；final local/causal/global（相同 architecture、init、seed）；same-anchor Domino 作为外部强基线。
- Metrics：raw EAL、global−local、global−causal、first-miss repair、harm、first-token、per-domain、prompt-cluster bootstrap 95% CI、三 seeds。
- Setup：最终 compact config，seeds 0/1/2；所有 hyperparameters 和 checkpoint-selection rule 在 test 前冻结。
- Success criterion：三 seed 方向一致；global−local/causal CI 排除0；相对 DFlash raw gain 明显超过现有 development best +0.285；test harm 单侧95% UCB≤5%。
- Failure interpretation：global对照不胜则删除 global claim；test 不复现则结果为 negative/inconclusive，不重新开 test 调参。
- Target：main result table + CI figure。
- Priority：MUST-RUN。

### Block 4: System Value and Failure Analysis

- Claim tested：离线 EAL 能转化为真实 speculative-decoding throughput。
- Dataset / split：冻结 test prompts；Qwen3-4B 首先覆盖 math/code/chat，4B 通过后才扩展 8B。
- Compared systems：DFlash、same protocol Domino、raw final selector、separate KEEP_BASE variant。
- Metrics：head latency、draft/verify/total latency、TPS、accepted length、peak memory、break-even、cluster CI；repair/harm 按 gold rank、base gap、position、domain 分层。
- Setup：相同 target/draft/checkpoint、block16、temperature0、dtype、hardware、warmup/timing protocol。
- Success criterion：raw selector 端到端 TPS CI 为正；KEEP_BASE 不替代 raw claim。
- Failure interpretation：EAL正但TPS负，只保留 offline selector claim并优先减小 D/layers；不在此时引入 slot。
- Target：main system table + failure figure。
- Priority：MUST-RUN（在 B3 通过后）。

### Diagnostic: Positive-Only Capacity Probe

- Claim tested：tested frozen inputs + function class 是否存在明显高于 compact model 的映射。
- Trigger：compact representation已正确训练但仍未达到有意义增益。
- Setup：D640/H10/L4/flat/compatibility，27,482,160参数；复用 B1 已选 objective/λ；512-block→10K→100K gates。
- Success criterion：高 probe held-out gain（约 +0.6 EAL 或 ≥15% oracle gap）只作为正 sufficiency witness；compact recover ≥70% 是工程目标。
- Failure interpretation：低结果只停止本 route，不宣称信息不存在。
- Priority：NICE-TO-HAVE / CONDITIONAL。

## Immediate Frozen Runs

- **R001 GPU smoke:** flat compatibility, global, D128/H8/L2, reach, λ=.1, margin=.1, 128 blocks, 5 epochs, batch16, lr6e-4。
- **R010–R012 capacity:** 与 R001 相同，λ={0,.1,.25}，120 epochs，batch32，seed0；same deterministic 128-block subset。checkpoint 优先保留任何完整 gate-passing epoch；单任务不因科学阴性退出失败，post-array aggregator 要求三个 artifacts 齐全并执行“至少一个 λ 通过”。
- **R020–R023 objective screen:** axial additive D64/H4/L1，25K prompts，9 epochs，seed0；historical D-PACE 与三个 reach/λ conditions。
- Positive probe 的 loss/λ 不提前猜测，必须复用 M2 冻结结果。

## Compute and Data Budget

- Core development estimated GPU-hours：约 36–67；conditional probe 额外 15–35。
- Data：现有 100K Open-PerfectBlend train canonical 64 GiB；现有 Phase-3 validation canonical 1.5 GiB。
- Human evaluation：不需要。
- Biggest bottleneck：validation_select 仅 147 prompts，不能支持正式 harm/CI claim；必须新增 prompt-disjoint calibration/test。

## Risks and Mitigations

- **旧 canonical 缺少独立 `base_greedy_ids` 字段：** 现有 collection 在 float32 logits 上直接 `topk(sorted=True)`，candidate0 是当时冻结的 base action；新 collector 写入 argmax witness。正式新数据必须含 witness。
- **bf16 survival underflow：** score normalization、gold probability、cumprod、utility 固定 float32，并有 dtype test。
- **checkpoint overfit validation：** development 和 confirmatory 明确分离，test 一次性 unseal。
- **known-primitives novelty：** 不靠命名 loss；必须由 coupled interaction、matched controls和吞吐证明。
- **capacity gate通过但 generalization差：** 这只证明 plumbing/expressivity，不当 held-out claim。
