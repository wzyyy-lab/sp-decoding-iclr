## Round 2 blocker 逐项关闭情况

### 1. LM-head 权威与数值 identity：CLOSED

- lexical rows 唯一定义为 `target.lm_head.weight[C]`。
- teacher score 唯一权威是直接 `gather(target.lm_head(T), C)`，不通过 residual cancellation 伪造标签。
- real-arithmetic identity、BF16 full GEMM、FP32 replay 与 bitwise identity 已明确区分。
- zero fallback 使用原始 `B`，因此 `U=0 ⇒ S=B`，而不是重新计算 base dot。
- P0 要求 16 个位置 selected-token mismatch 为零，并报告 direct teacher 与 residual cancellation 的 FP32 容差。

### 2. 连续 clean support 与 prompt balance：CLOSED

更新后的条件是正确且必要的：

\[
v_{bi}
=
1[y_{bi}\in C_{bi}]
1[\arg\max_v \operatorname{lm\_head}(T_{bi})_v=y_{bi}]
1[\operatorname{stable}_{bi}],
\qquad
M_{bi}=\prod_{j\le i}v_{bj}.
\]

关键改进是第二项现在使用**权威 full-vocabulary top1**，不再允许“target top1 在候选集外、gold 只是候选内最高”误入 support。

stable row 同时要求：

- BF16 authoritative 与 FP32 replay 的 full-vocabulary top1 ID 一致；
- authoritative top1–top2 margin `>2ε_num`；
- argmax 不一致行既不能进入 support，也不能用于校准 `ε_num`。

latent、safe、KL 共用同一个连续 prefix support。所有 loss 先在 block 内约化，再通过 uniform-prompt、uniform-effective-block 采样实现 prompt balance；评估也先 block 后 prompt。该定义不再把相关 row 当独立样本。

### 3. Stable safe-risk：CLOSED

已固定为 FP32：

\[
\tau\operatorname{logsumexp}
\left(
0,\{\log w_i+(\gamma-\widetilde m_i)/\tau\}_{i\in M}
\right),
\]

masked 项为 `-∞`，明确禁止显式 exponentiation。它也已正确降格为 early-biased worst-prefix surrogate，而非形式化 safety certificate。

### 4. KL 温度：CLOSED

固定 `T=2` 且乘 `T²`；使用相同连续 support 和 prompt-balanced reducer；没有温度 grid 或第二个 logit-regression loss。no-latent arm只令 `α=0`，其余架构、数据、优化器、更新数和 loss 均匹配，因此能够检验 latent supervision 的增量价值。

### 5. PCA/RMSE 错误 hard gate：CLOSED

- hidden RMSE、whitened RMSE、candidate correction RMSE 只作诊断。
- 没有绝对 latent RMSE GO/STOP。
- PCA/SVD 明确不是 candidate-space upper bound，也不能触发 STOP。
- P1 binding gate 已改为 candidate agreement、oracle-gap recovery、harm 和 J2。

### 6. Zero-init、visibility 与梯度 receipts：CLOSED

P0 已正确拆分：

- zero-init 输出严格回退 base；
- zero-init 时 remote perturbation 只要求改变 `g_i` 或 Jacobian，同时 `S` 保持 base；
- deterministic nonzero probe `U` 或 trained checkpoint 必须证明 remote node 能改变 `S_i`；
- 初始 `grad(U)` 有限且非零；
- 初始 upstream gradient 为零被明确识别为 zero-init 的预期现象；
- 一次 optimizer update 后 upstream global-mixer gradient必须有限且非零；
- production noncausal mask、simultaneous output 和 fail-closed scope 均有 receipt。

不存在以 zero identity 与 remote-score sensitivity 相互矛盾地做 gate 的问题。

### 7. Exact architecture 与参数边界：CLOSED

架构已精确冻结为：

- D256、H8、两层 pre-norm encoder；
- FFN1024/GELU；
- flat 256-node noncausal sequence；
- 16 learned queries；
- 一次 query-to-all-nodes MHA+LN；
- dropout 0；
- 无 query FFN；
- 无独立 anchor projection；
- 无第二输出 head、continuous gate 或 expert；
- 总可训练参数 **3,826,688**。

local mask 只存在于 matched offline ablation，不能加载为 production checkpoint。不存在“约 3.9M”所留下的实现漂移空间。

### 8. EAL+1 联合系统门：CLOSED

已同时保留三层约束：

1. immutable fixed EAL 最低门 `8.3254859086`；
2. SGLang 前设计目标 EAL `≥9.0`；
3. 每个完整 cycle 必须满足

\[
T_P/T_D
\le
\frac{\mathrm{EAL}_P+1}
{1.15(\mathrm{EAL}_D+1)}.
\]

在 Domino EAL 7.2395529640 下，等 cycle time 需要 EAL 8.4754859087；EAL 9.0 只允许 PCLD cycle 最多约 1.05535× Domino。head-only 1.20× 只是 P0 development guide，不能授权 systems claim。

## 方法与 novelty 判断

PCLD-16R 现在不是 PLC 的简单重做：它不预测 Domino `W_s s`，也不在线复现 Domino GRU state；16 个 clean target predictive residual 完整覆盖 anchor→`y0` 至 `y14`→`y15`。它也不仅是 JAPD 的固定 candidate-score head：共享 hidden residual 通过每样本动态 LM-head candidate matrix映射到分数。

但 novelty 仍被正确设为**条件性主张**：

- 若 global 与 local statistically equivalent，则“full-block remote context”机制 claim 失败。
- 若 global 与 no-latent statistically equivalent，则 latent residual 不能声称优于 matched candidate distillation，方法应被视为 score/KL 重参数化。
- predictive latent alignment、target knowledge、parallel dependency 和 acceptance-decay 问题本身分别受 YLLKF、DFlare、PTP、DSpark 约束，不能声称首创。

可辩护贡献仅是：在严格禁止 sequential feedback、额外 target inference 和 multipath 的 full16 场景中，candidate-conditioned global student 一次蒸馏并输出单条 clean trajectory，且两个 matched controls 与最终系统结果共同证明机制有效。这个边界准确且不过度。

## 实验计划判断

- **P0** 最小且必要：只验证接口、数值、非因果 visibility、zero-init 动力学、参数与完整 eager cost。
- **P1** 只验证实现和 same-set capacity，不被允许支持泛化 claim。
- **P2** 是核心机制 falsifier：三 seed、matched global/local/no-latent、同 data/order/optimization，diagnostic 一次性共同开启；paired prompt bootstrap 的统计单位正确。
- **P3** 的 25K/100K 是条件式 scale，而不是失败后的数据救援；25K 的 EAL、slope、两个 control 与域退化共同控制是否进入 100K。
- **P3.5/P4** 将 acceptance 与 cycle cost 联合，最后分别用 sealed fixed、fresh dynamic 和 same-stack SGLang 关闭统计、在线 rollout 和系统 claim。

这已经是最小充分验证，不应加入 rank/width/loss/temperature sweep。

## Simplification Opportunities

**NONE。**

PCA 最好直接不实现；即便保留，也只能是 train-only 非门控诊断。除此之外再删任一核心 arm 或 receipt 都会损害 mechanism attribution 或合同审计。

## Modernization Opportunities

**NONE。**

当前 predictive-state distillation 的作用明确。引入额外 planner、RL、sequential module、target routing 或 inference-time search 不会让主张更干净，并可能直接违反 immutable contract。

## 最强未来拒稿理由

最强拒稿风险已经从“方法定义不自洽”转为一个清楚的经验假设：

> 10.5971817298 的 teacher ceiling 只证明 clean target candidate scores 有 headroom；它不证明在线 DFlash lattice 能在 disjoint prompts 上预测 `T-H`。PLC、PGCF、JAPD 和 R043–R046 已表明 capacity、更多参数与 target supervision 都可能不产生 transfer。

因此，只要 P2 的 global-local 或 global-no-latent 任一对照不通过，机制 claim 就应失败；若 fixed/dynamic EAL 或联合 cycle/SGLang gate 不通过，系统 claim 就应失败。规范已经为这些负结果提供了明确 STOP，而没有预留 post-hoc rescue。

## GAP

距离实际顶会 claim 只剩**实证缺口**，不是方法规范缺口：需要 P0 receipts、P1 capacity、P2 disjoint causal controls，以及条件式 scale 和 sealed systems result。不得把这些待证假设当作当前已证事实；反过来，也不应因为尚未执行实验而继续改动已经冻结且可证伪的方法。

## 最终结论

**无剩余方法 blocker。批准冻结 PCLD-16R 进入 P0，并仅按预注册 gate 逐步推进。** 不授权架构扩展、额外路线、直接 100K、target-online、serial/iterative 或 multipath 方案。
