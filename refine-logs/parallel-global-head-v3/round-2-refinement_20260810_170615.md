# Round 2 Refinement：PCLD-16R Frozen Method Contract

> Status: all Round-2 blockers are addressed at the method-specification level.

## 1. Unchanged problem anchor

- **Bottom-line problem:** preserve DFlash one-forward block-parallel drafting while using a lightweight head to solve low accepted length. Fixed and dynamic EAL must each be at least 1.15x same-job released Domino; final same-stack A40 SGLang throughput must also be at least 1.15x.
- **Must-solve bottleneck:** development base EAL is 6.0685131195, Domino is 7.2395529640, the formal 1.15x EAL floor is 8.3254859086, and the pure-base Top16 oracle is 10.9092565598. PGCF/JAPD showed that Top16 coverage, small-set capacity and head latency are not enough; the unresolved problem is cross-prompt prediction of a safe joint clean trajectory and rare early-prefix harm.
- **Non-goals:** no GRU/autoregressive head, selected-token feedback, serial target seed/decode, iteration/Jacobi, beam/tree/trie/forest/multipath, extra online target inference, same-set substitution, or post-hoc D512/loss/schedule rescue.
- **Hard online contract:** consume all 16 positions once; every output position sees all 16 positions through a full noncausal mixer; emit one score tensor shaped [B,16,16]; one simultaneous per-position argmax emits exactly one [B,16] chain; Top16 is only a candidate axis.
- **Final success:** sealed fixed and fresh dynamic EAL each exceed same-job Domino by at least 1.15x with no domain regression, and paired same-stack A40 SGLang TPS has 95% CI lower bound at least 1.15x.

## 2. Frozen online dataflow

One ordinary released DFlash forward supplies:

\[
H\in\mathbb{R}^{B\times16\times2560},\qquad
Z\in\mathbb{R}^{B\times16\times V}.
\]

Candidate IDs and authoritative base scores are produced once:

\[
(B,C)=\operatorname{Top16}(Z.float()),\quad
C\in\mathbb{N}^{B\times16\times16}.
\]

The only lexical projection is

\[
W_{\rm lm}=\texttt{target.lm\_head.weight},\qquad
e_{ik}=W_{\rm lm}[C_{ik}].
\]

Input embedding aliases are never an authority assumption, even though the current Qwen3-4B checkpoint ties them.

The head returns one tensor \(S[B,16,16]\), and production emits only

\[
\hat y_i=C_{i,\arg\max_k S_{ik}},\quad i=0,\ldots,15.
\]

There is no intermediate token selection and no output token is fed back into the head.

## 3. Exact frozen architecture

### 3.1 Nodes

Use parameter-free RMS normalization for \(H_i\) and \(e_{ik}\). The five bounded scalar channels are the existing full-vocabulary log probability, Top16 conditional log probability, rank-1 gap, retained Top16 mass and conditional entropy. For all 256 nodes:

\[
x_{ik}=W_H\operatorname{rms}(H_i)
+W_E\operatorname{rms}(e_{ik})
+W_f f_{ik}+p_i+r_k.
\]

Apply one affine LayerNorm in D256 after this sum and before the first encoder
block. The H and lexical projections include bias; the parameter-free RMS
normalization uses epsilon \(10^{-6}\).

There is no independent anchor input or anchor projection. Anchor information already enters the ordinary DFlash hidden rows.

### 3.2 Full-block mixer and query

- model dimension 256;
- 8 attention heads;
- 2 pre-norm encoder blocks;
- FFN width 1024 with GELU;
- flat sequence length 256;
- production attention mask is always None;
- dropout 0;
- 16 learned position queries;
- one query-to-all-256-nodes cross-attention;
- no query FFN.

Each query sees the same complete set of 256 final nodes. A local block-diagonal mask exists only in the matched offline ablation and can never be loaded as a production checkpoint.
The query output is exactly
\(\operatorname{LayerNorm}(q+\operatorname{MHA}(q,X,X))\); this tensor is
\(g\). There is no additional projection between it and \(U\).

### 3.3 Residual score

\[
g_i\in\mathbb{R}^{256},\qquad
\widehat\Delta_i=Ug_i\in\mathbb{R}^{2560},
\]

\[
S_{ik}=B_{ik}+\langle e_{ik},\widehat\Delta_i\rangle.
\]

Both weight and bias of \(U\) are zero initialized.

Exact trainable parameter contract:

| Component | Parameters |
|---|---:|
| H and lexical projections | 1,311,232 |
| 5-scalar projection | 1,536 |
| position/rank embeddings | 8,192 |
| node input LayerNorm | 512 |
| two D256/FFN1024 encoder blocks | 1,579,520 |
| 16 queries, cross-attention and query LayerNorm | 267,776 |
| U: 256 to 2560 | 657,920 |
| **Total** | **3,826,688** |

Any query FFN, second output head, independent anchor projection, continuous gate or extra expert is a contract violation.

## 4. Offline teacher and numerical authority

For clean target tokens \(y_0,\ldots,y_{15}\), one offline teacher-forced target pass consumes context + anchor + \(y_0,\ldots,y_{14}\). Its final-norm rows satisfy:

\[
T_i=\operatorname{TargetHidden}(\text{anchor},y_0,\ldots,y_{i-1}),
\quad i=0,\ldots,15.
\]

Row 0 predicts \(y_0\); row 15 predicts \(y_{15}\). The latent label is

\[
\Delta_i^*=T_i-H_i.
\]

The authoritative candidate teacher is not reconstructed through cancellation. It is gathered directly:

\[
S^*_{ik}
=
\operatorname{gather}
\left(
\texttt{target.lm\_head}(T_i),C_{ik}
\right).
\]

The real-arithmetic relation

\[
B_{ik}+\langle e_{ik},T_i-H_i\rangle
=\langle e_{ik},T_i\rangle
\]

is a mechanism explanation and FP32 tolerance receipt, not a bitwise BF16 claim.

Online step-0 identity uses the original \(B\), not a recomputed dot:

\[
U=0\Longrightarrow S=B.
\]

It therefore requires zero token mismatches against pure DFlash on all 16 positions.

### 4.1 Stable-row calibration

During train-sidecar materialization only, replay target logits in the authoritative BF16 full-GEMM path and an FP32 linear path. Center each row on the authoritative top-1. Let \(\epsilon_{\rm num}\) be the maximum centered discrepancy among rows whose argmax already agrees. Freeze this scalar before select/diagnostic.

A row is stable only when the authoritative BF16 and replay FP32
full-vocabulary top1 IDs agree **and** the authoritative top1-top2 margin is
greater than \(2\epsilon_{\rm num}\). A disagreeing row can never calibrate
\(\epsilon_{\rm num}\) or enter support, regardless of its reported margin.
Stable classification is a teacher-label hygiene rule; final fixed/dynamic EAL
still uses the ordinary verifier.

## 5. One strict support shared by every loss

Let

\[
v_{bi}=
\mathbf 1[y_{bi}\in C_{bi}]
\mathbf 1[
\arg\max_v\texttt{target.lm\_head}(T_{bi})_v=y_{bi}
]
\mathbf 1[\operatorname{stable}_{bi}].
\]

The only trainable support is the continuous prefix

\[
M_{bi}=\prod_{j\le i}v_{bj}.
\]

The second condition uses authoritative full-vocabulary target top1, not merely
the best token inside the DFlash candidate set. The first out-of-K token,
teacher/gold mismatch or unstable row removes that row and the entire suffix
from latent, safe and KL losses. A block with zero support is excluded from the
effective training set.

Each loss is first reduced within one block over its valid support. Prompts are then weighted equally: training samples prompts uniformly, then samples one effective block uniformly within each chosen prompt. Evaluation averages blocks within prompt and then prompts. Block count can never determine prompt weight.

## 6. Frozen objective

### 6.1 Magnitude-preserving latent loss

On the training split only:

\[
q_j=\max(\operatorname{Std}_{train}(\Delta^*_{:,j}),10^{-3}).
\]

Freeze \(q\), then use:

\[
L_{\rm latent}^{(b)}
=
\frac{1}{|M_b|\,2560}
\sum_{i\in M_b,j}
\operatorname{SmoothL1}
\left(
\frac{\widehat\Delta_{bij}-\Delta^*_{bij}}{q_j}
\right).
\]

Raw hidden RMSE, whitened RMSE, candidate-correction RMSE and margin agreement are reported. No absolute hidden-RMSE value is a GO gate.

### 6.2 Stable early-biased worst-prefix risk

For gold candidate rank \(r_{bi}\):

\[
\widetilde m_{bi}
=
\frac{
S_{bi,r_{bi}}-\max_{k\ne r_{bi}}S_{bik}
}{
\max(\operatorname{Std}(B_{bi,:}),0.25)
}.
\]

With \(w_i=(16-i)/16,\gamma=0.1,\tau=0.1\), compute in FP32 only:

\[
L_{\rm safe}^{(b)}
=
\tau\operatorname{logsumexp}
\left(
0,
\left\{
\log w_i+\frac{\gamma-\widetilde m_{bi}}{\tau}
\right\}_{i\in M_b}
\right).
\]

Masked entries are negative infinity. Explicit exponentiation is forbidden. This is an early-biased worst-prefix surrogate, never a safety certificate.

### 6.3 Matched temperature-2 candidate distillation

\[
L_{\rm KL}^{(b)}
=
T^2\operatorname{KL}
\left(
\operatorname{softmax}(S_b^*/T)
\parallel
\operatorname{softmax}(S_b/T)
\right),
\qquad T=2.
\]

The KL is rowwise masked by \(M_b\), averaged inside the block, and prompt balanced. There is no second logit-regression loss and no temperature grid.

The only total objective is

\[
L=L_{\rm safe}+\alpha(t)L_{\rm latent}+0.1L_{\rm KL}.
\]

\(\alpha(t)\) decreases linearly from 1.0 to 0.1 over the first 30% of updates and remains 0.1. The matched no-latent arm uses the identical architecture/data/order/optimizer/updates with \(\alpha=0\).

## 8. Claim-driven experiment sequence

### P1: 512-block same-set mechanics/capacity

One frozen D256/H8/L2 recipe, 8,000 updates. Binding gates:

- teacher candidate argmax agreement at least 99%;
- oracle-gap recovery at least 95%;
- harm at most 1%;
- strict J2/multi-repair success at least 99%.

Candidate-logit RMSE, teacher-margin agreement and hidden residual errors are fully reported but not independent hard gates. Failure permits only a demonstrated implementation or numerical correction, not a width/loss/schedule sweep.

### P2: three-seed cross-prompt mechanism gate

Use the frozen 1589 train / 199 internal-select / 199 untouched diagnostic prompt split. Run global, parameter-matched local-mask and matched no-latent arms for seeds 0/1/2 with identical optimization and checkpoint cadence. All architecture and checkpoint decisions use train/select only; the three diagnostic arms open together once.

GO requires:

- every global seed diagnostic EAL at least base + 0.30;
- aggregate oracle-gap recovery at least 20% and strict J2 at least 40%;
- every seed harm at most 1%;
- chat/code/math each at least pure base;
- prompt-paired global-minus-local EAL at least 0.15 with 95% CI lower above zero;
- prompt-paired global-minus-no-latent EAL at least 0.15 with 95% CI lower above zero.

For the two paired mechanism comparisons, first average each prompt across seeds, then bootstrap prompts with a frozen 10,000-draw seed. Same-set capacity cannot satisfy P2.

### P3: conditional 25K and 100K scaling

Only P2 GO authorizes strict full16 OPB 25K-prompt collection. Three seeds share one label sidecar. Authorization for 100K requires all of:

- held-out EAL at least 7.8;
- positive held-out slope from P2 to 25K;
- global-local and global-no-latent paired CI lower bounds remain above zero;
- no domain regression.

If 25K EAL is below 7.55 or either mechanism control disappears, stop. Falling train loss alone never authorizes 100K.

### P3.5: joint accuracy-cycle feasibility

Before SGLang integration, measure complete eager cycle time and apply:

\[
\frac{T_P}{T_D}
\le
\frac{\mathrm{EAL}_P+1}
{1.15(\mathrm{EAL}_D+1)}.
\]

The immutable minimum accepted-length claim gate remains 8.3254859086, but the design target is EAL at least 9.0. With Domino EAL 7.2395529640:

- equal cycle time requires EAL at least 8.4754859087;
- EAL 9.0 permits PCLD cycle time at most 1.0553548490x Domino.

No 100K continuation beyond its pre-registered endpoint and no SGLang engineering are authorized when the measured EAL/cycle pair cannot support 1.15x TPS.

### P4: sealed claims

Freeze architecture, weights, checkpoint, numerical calibration and kernel before opening:

1. sealed fixed prompts: EAL at least 1.15x same-job Domino, design target at least 9.0, all domains non-regressing;
2. fresh dynamic rollout: EAL at least 1.15x same-job dynamic Domino;
3. same-stack A40 SGLang batch1 paired workload: TPS ratio 95% CI lower at least 1.15.

Any failure remains inside the single-chain parallel architecture; it cannot be replaced by serial target inference, iteration or multipath.

## 9. Controls, claims and literature boundary

The only efficacy arms are pure DFlash, released Domino, PCLD global, parameter-matched local mask and matched no-latent. PCA/SVD may be reported as a train-only latent diagnostic, but it is not a candidate-space upper bound and can never be a hard stop.

The defensible contribution, only if both controls and all final gates pass, is:

> In a full16 speculative drafter that explicitly forbids sequential feedback, clean autoregressive predictive residuals are distilled into a candidate-conditioned full-block noncausal student. One invocation emits one 16-token chain, and matched evidence shows that both remote block context and residual supervision improve held-out accepted prefix and end-to-end throughput.

Predictive latent alignment, target-knowledge injection and parallel dependency modeling are not individually novel: Your LLM Knows the Future, DFlare, PTP and DSpark define those boundaries. PLC, PGCF, JAPD and R043-R046 remain direct negative evidence. The claim is the constrained combination plus causal controls and systems result, not any primitive by itself.
